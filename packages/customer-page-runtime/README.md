# 고객 페이지 표시 경계

빌드 진입점: `apps/customer-workspace/scripts/build-shared-runtime.mjs`.

에디터가 사용하는 페이지 렌더링 함수와 공용 화면 모듈을 같은 소스에서 읽는다. 고객용 달력이나 개체 스타일을 별도로 작성하지 않는다. 관리자 화면 초기화와 데이터 저장 기능은 실행하지 않는다. 문서별 상태와 DOM 조회 범위를 분리해 다른 페이지 표시 인스턴스와 혼합되지 않게 한다.

생성 결과는 앱의 `public/generated/page-runtime`에만 두며 Git에 저장하지 않는다. manifest에는 사용한 원본 파일의 해시를 기록한다. 새로운 표시 모듈을 추가할 때는 의존성 목록과 동일 문서 검증을 함께 갱신해야 한다.

이 경계는 프로젝트 서버 저장·인증·사진 업로드·인쇄 출력을 제공하지 않는다.
