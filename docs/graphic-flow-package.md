# 구성 03 · 흐르는 곡선

아이보리 바탕, 딥 틸과 살구색의 가장자리 곡선으로 구성한 순수 SVG 배경이다. 사진 1개와 연도·학교정보는 배치 예제의 별도 개체이며 배경에 합치지 않는다. 사진 위치에 맞춘 구멍이나 고정 하단 띠를 만들지 않는다.

`cover-curve-03`, `teal-apricot` 설정을 저장하며 농도·간격·크기 조정과 기존 표지 기반 페이지 생성 흐름을 지원한다. 월별 색상 변화는 곡선 계열을 유지한다. 기존 구성 01·02의 생성 경로는 유지한다.

관리자 인증을 거친 라이브러리 최초 조회에서 표지가 포함된 시작 패키지를 한 번 등록한다. 기존 동일 ID의 자산이나 패키지는 덮어쓰지 않는다. 설치 완료 표시를 보존하여 삭제한 패키지를 다시 생성하지 않는다. 실제 운영 데이터 등록 여부는 관리자 화면에서 별도로 확인해야 한다.

기본 재단 규격은 260×180mm이며 기존 템플릿 매핑이 3mm 도련을 포함한 266×186mm 배경을 구성한다. SVG 경로는 재단선 밖으로 이어진다. 썸네일만 WebP이며 인쇄용 원본은 SVG다. 자동 검사와 SVG 화면 확인은 최종 CMYK PDF·실인쇄 품질 검증을 대체하지 않는다.
