# 배포 단계

## 1. 독립 개발 환경

현재 저장소에서 Designer Studio와 Runtime을 빌드·테스트한다. 이 단계에서는 우리학교인쇄 운영 서버와 연결하지 않는다.

## 2. GitHub 저장

문서, 소스, 스키마, 테스트, 결정 기록, 로드맵을 private 저장소에 저장한다. 비밀정보와 운영 환경값은 제외한다.

## 3. 사용자 MVP 통합 환경

기존 Academic Calendar Workspace MVP를 Runtime Contract에 연결하고 가격 산정·주문 준비·인쇄 파일 생성을 함께 검증한다.

## 4. 통합 QA

대표 템플릿과 실제 학교 데이터를 사용해 화면, 금액, 페이지 수, 인쇄 규격, 파일 무결성을 확인한다.

## 5. 우리학교인쇄 운영 서버 배포

독립 환경과 통합 QA를 통과한 버전만 운영 서버 규칙에 맞춰 배포한다. 배포 방식과 환경변수, 로그, 파일 저장 정책은 운영 담당자와 확정한다.
