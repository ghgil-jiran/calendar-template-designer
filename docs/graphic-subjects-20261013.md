# 그래픽 자산 세부 주제 통합 · 2026-10-13

- 전체 자산에서 그래픽 패키지 소속 자산 제외. 목록과 생성 화면이 같은 세부 주제를 사용.
- 공통 주제 25개: 기존 8개 유지, 책·독서/교실·학교 시설/과학·실험/미술·공예/입학·졸업/학교 행사·기념/봄·여름·가을·겨울/꽃/나무·잎/새/곤충/바다 동물/기하학·선 장식/사진 프레임 추가.
- 새 이미지 만들기: 주제, 생성 개수(기본 1개), 선택 추가 요청 → 벡터 이미지 만들기 → 결과 저장. 주제별 허용 개수 표시 및 서버 검증.
- 테마 관리 홈/수정/정보 저장 등 기존 UI 제거. 내부 생성 묶음 및 기존 데이터는 보존.
- 내부 큰 분류는 선택 주제에서 자동 결정하므로 사용자에게 두 번 묻지 않음.
- 새 이미지의 subjectId 저장. 기존 자산은 저장된 테마 종류/이름/개체 이름에서 주제 표시. 원본 및 이전 묶음 연결 삭제·이전 없음. 상세에서 공통 세부 주제 지정 가능.
- 전체 자산은 명시적 패키지 소유권, 패키지 페이지 연결 및 이전 패키지 명명 규칙에 해당하는 자산을 제외. 패키지 편집의 독립 목록 유지.
- 검증: 전체 build 및 Studio 863개 통과. 주제 목록 일치, 한 번 제출로 생성, 패키지 제외, 기존 연결 보존, 주제별 개수 검증.
- 실제 AI 디자인 품질과 로그인 화면 시각 검증은 미실시. Preview만 배포.
