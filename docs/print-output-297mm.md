# 탁상형 확대 인쇄 출력

- 원본 편집 규격: 260×180mm. 원본 템플릿과 기본형 CMYK PDF는 변경하지 않는다.
- 확대형: 가로 297mm, 세로 180×297/260=205.615384615…mm. 화면·파일명은 205.615mm로 표시한다.
- 균등 배율: 297/260. 최종 사방 도련 3mm, 재단선은 목표 규격에서 새로 생성한다.
- 5단계 ‘출력 규격·최종 확인’에서 확대형을 선택하고 ‘확대 PDF 생성·검사’를 요청한다.
- 기존 로컬 워커 저장소 `ghgil-jiran/-v1.1`의 해당 기능 브랜치를 갱신한 뒤 표시된 `--job` 명령으로 실행한다. 원본 CMYK 재변환·브라우저 재렌더는 하지 않는다.
- 원본 완료 잡 ID·패키지 SHA에 묶인 별도 잡/PDF/검사 결과를 저장한다. 확대 잡은 원본 검사 이력을 대체하지 않는다.
- 이미지·ICC·압축·마스크 보존, 페이지 수, PDF 박스, PDF/X·CMYK·K100·벡터 구조를 검사한다. 확대 후 이미지 사용 위치의 유효 DPI를 재측정하고 기준 미달·미지원 구조는 확인 필요로 기록한다. 원본 수동 비교·육안 승인 결과를 확대본 통과로 복사하지 않는다.
- Preview는 인쇄 API의 새 Preview와 함께 연결해야 한다. `USER_SERVICE_PRINT_PREFLIGHT_API_URL`은 해당 Preview 브랜치에만 설정한다. Production 변경은 별도다.

검증: 확대 PDF 및 API 테스트 8개, 원본/확대 이력 분리 2개 통과. 실제 고객 28면 PDF·로컬 워커·관리자 인증을 포함한 통합 검증은 별도다. 전체 에디터 빌드에는 수정 전에도 재현되는 기존 실패 항목이 남아 있다.
