# 2027학년도 · 벽보형 샘플 B · 2페이지 일정형

- 각 면 A2 세로 420×594mm, 사방 3mm 도련 포함 426×600mm.
- 샘플 D의 보관 연력 배경(`assets/sample-d-v4/annual.pdf`)을 참고해 사선·삼각형·세 점을 벡터로 재구성한다. 제본 구멍 장식은 벽보형에 넣지 않는다.
- 1면 남색·분홍, 2면 청록·살구. 순수 벡터 CMYK 배경 PDF 2개를 원본으로 등록하고 PNG는 화면 미리보기에만 쓴다. PDF에 래스터 이미지와 글꼴은 포함하지 않는다. 이 구조 검사는 PDF/X·실물 인쇄 승인과 구분한다.
- 1면 2027년 3~8월, 2면 2027년 9월~2028년 2월. 각 6개월 2열×3행, 고정 6주, 월 연결 offset 0/6 유지.
- 월 하단 목록은 없고, 날짜 칸 안에 공휴일·기념일·학교 일정·24절기·음력을 모두 표시한다. 음력은 기존 기본 달력과 같은 저장 참조 자료를 사용하며 매일 음력을 새로 생성하지 않는다.
- 기본 인쇄 크기: 월 제목 26pt, 요일 11pt, 날짜 15pt, 부가정보 8pt, 학교 일정 9pt. 월 간격 6mm, 안쪽 여백 2mm. 공간 부족 검사는 기존 공통 Runtime을 사용한다.
- 교표·학교명·영문명은 각 면 하단에 별도 연결 개체로 구성하며 완성형 로고 전환을 위한 공통 그룹을 유지한다.
- 달력 유형 → 벽보형 → **2페이지형 → 샘플 B · 2페이지 일정형 만들기**. 관리자 세션의 기존 `/api/poster-sample`에서 `geometric-b` 변형으로 두 PDF를 등록한 후 별도 stableKey의 새 초안을 만든다. 기존 샘플 A·D와 기본 2페이지형은 수정하지 않는다. 실패 후 같은 버튼으로 재개할 수 있으며 이미 등록된 B는 덮어쓰지 않는다.
- 실제 등록·화면 확인은 사용자가 수행한다. 검증 후 저장·게시하면 기존 사용자 서비스 공통 Runtime에서 같은 개체를 표시한다. 자동 로그인과 브라우저 인증 대행은 사용하지 않는다.
