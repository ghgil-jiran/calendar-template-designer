# Poster editing policy v2

Applies to one-page, two-page and duplex poster types. Existing authored page order, month offsets and object placement remain unchanged. Opening/editing normalizes known shipped legacy font sizes once; saving or preparing a print/published package persists the policy version. A subsequent authored change is not reset. The shared renderer is also used by customer previews.

The month grid inspector has collapsible layout/grid, month colors, sizes, public calendar and school schedule groups. Each displayed month has a title-bar color. A row color option retains the previous grouping behavior. Public calendar placement supports the same four layouts as desk calendars, with a default of inheriting the desk setting. Holidays use the holiday color; anniversaries, solar terms and lunar dates inherit the date color unless configured individually. Visibility follows the existing calendar data options.

Default date text is 10 units for twelve months and 13 units for six months; event text is 5/6, reference text 4.5/5.5, and list text 6/7. Units use the shared page-width reference of 1000; they scale with the entire calendar. Period bars reserve bottom space by week and lane instead of covering cell text at the old fixed spacing.

The placement checkbox copies geometry only to matching header objects on other pages: logo, linked school text, year and academic calendar heading. It never copies text content or changes monthly grids. Poster zoom uses CSS print dimensions at 96 px per inch for 100%, with an initial fit to both viewport dimensions and a 5–400% manual range. This is CSS physical sizing; actual monitor millimeters depend on browser/OS zoom and display calibration. Desk zoom retains its existing reference canvas.
