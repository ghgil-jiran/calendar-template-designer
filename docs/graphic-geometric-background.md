# 구성 04 · 기하학적 선

사용자가 승인한 선 중심 AI 이미지 시안의 원호·사선·교차점 구도를 순수 SVG 경로로 재구성했다. 원본 이미지의 질감은 제외하고 아이보리·네이비·구리색·블루그레이의 제한된 팔레트를 사용한다. 사진과 문자, 외부 참조, 필터, 콘텐츠 영역을 위한 절단을 포함하지 않는다.

`cover-geometry-04`, `backgroundRevision: 4`, `navy-copper` 설정으로 재현한다. 기존 구성 01~03의 원본과 재현 규칙은 보존한다. 생성 UI에서 같은 구성을 새 자산으로 저장하거나 패키지 표지로 사용할 수 있다. 사진 배치 영역은 예제일 뿐 SVG를 잘라내지 않는다. 표지 기반 페이지 생성은 원래 구도와 선을 유지하고 앞뒤 방향 및 월별 색상을 변경한다.

관리자 인증을 거친 라이브러리 조회 시 고유 ID의 시작 패키지와 표지 SVG를 한 번 등록한다. 설치 표시가 남아 있어 삭제한 패키지를 다시 만들지 않으며 기존 자산·수정 내용은 덮어쓰지 않는다. 썸네일은 WebP이고 인쇄용 원본은 SVG다. 서버 데이터 등록 결과는 인증된 관리자 화면에서 별도로 확인해야 한다.

기본 규격은 재단 260×180mm, 기존 템플릿 매핑은 3mm 도련을 포함한 266×186mm로 구성한다. 선은 재단선 밖으로 연장되어 있다. 자동 검사와 SVG 시각 확인은 최종 CMYK PDF 및 실제 인쇄 확인과 구분한다.
