# 이미지 품질 정책 — 2026-10-05

기존 출력 설정의 imageQualityPolicy를 print 프로필에 포함하여 새 템플릿 패키지 버전에 고정한다. PDF 출력 프로필의 300DPI·PDF/X-4·CMYK·Japan Color 2011 Coated·K100은 유지한다.

- schemaVersion: image-quality-policy.v1
- recommendedDpi: 300 (초기값)
- orderMinimumDpi: 200 (초기값)
- upscaleTargetDpi: 300 (초기값, 실제 보정 미구현)
- 설정은 72~1200의 정수, 주문 최소 ≤ 권장 ≤ 보정 목표. 정책이 없으면 초기값을 사용하며 잘못된 정책은 차단한다.

원본 픽셀과 실제 배치의 mm 크기, cover/contain, 확대 배율로 유효 DPI를 계산한다. 주문 최소 미달은 차단, 최소 이상·권장 미달은 경고와 동의 필요, 권장 이상은 통과한다. 동일 원본은 배치마다 검사한다. 회전·크롭은 원본 픽셀을 추가하지 않는다.

사용자 검사에서는 실제 연결한 사용자 원본만 포함하고 템플릿 샘플·사용하지 않은 업로드는 제외한다. 이미지 선택과 교표 입력 화면에서 작은 글씨·선의 선명도를 안내하고 자동 교표 교체·배경 제거·업스케일을 약속하지 않는다. 문서·배치 변경 시 검사와 동의를 초기화한다.

접수 서버는 저장 문서의 정확한 템플릿 버전과 패키지 SHA-256으로 기준을 확인하고, 보관 원본의 픽셀 크기를 다시 읽어 저장 Runtime 배치와 대조한다. 교화·교목·교가 같은 복합 개체는 공통 렌더러에서 측정한 내부 영역을 부모 영역 안인지 검사하여 사용한다. 이 측정 근거는 접수 기록에 남기며 관리자의 독립 검사와 시각 검수를 대신하지 않는다. imageQualityInspection에 기준·배치·원본 크기·검사 시각·upscaleApplied:false를 보관한다. 기존 접수 데이터와 사용자 원본은 수정하지 않는다.

관리자 빠른 검사는 저장된 교정본을 기준으로 기준 충족·보정 검토·원본 교체 필요·배치 확인 불가를 표시한다. 보정 검토는 처리 완료가 아니다. 실제 업스케일은 다음 단계에서 기존 인쇄 품질 검사 경로에 연결하며 이번에는 Worker와 인쇄 파이프라인을 변경하지 않는다.
