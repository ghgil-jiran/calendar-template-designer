# 페이지 설정의 용도별 구성안 — 수정 전 기준 (2026-09-29)

대상은 260×180mm 표준 탁상달력이다. `page-settings-standard-audit-20260929.md`의 현행 조사 결과를 바탕으로 한 **수정 설계안**이며 아직 구현하거나 Preview에서 모든 조합을 검증한 결과가 아니다.

진행 상태(2026-09-29): 25개 구성 형태의 핵심·기본 개체와 허용 배치 초안을 `ai-design/page-composition-policy.js`에 분리했다. 표지·월력 앞면·뒷표지에서 구성 형태를 **직접 변경할 때** 초기 개체와 첫 배치를 이 규칙으로 다시 선택한다. 월력 뒷면의 구성 형태를 변경할 때도 기본 개체·배치·콜라주 최소 사진 수를 연결했다. 간지·안쪽면의 용도를 변경하면 학교 소개·학사일정 등 해당 용도의 기본 개체를 선택하고, 화면에서 필수 개체 해제를 막는다. 저장 시 학교 상징의 내용이 비었거나 사용자 정의의 개체가 없는 면은 안내한다. 연력 용도를 선택한 실제 면에는 네 연력 배열을 제공하고, 선택한 배열을 12개월 날짜 개체에 적용한다. 연력 설정 카드는 같은 연력 계산 결과를 축소해서 표시한다. 기존 저장 템플릿을 열기만 해서는 개체를 바꾸지 않는다. 학교 상징 카드는 선택된 상징과 악보선을, 학사일정·Yearly Plan 카드는 실제 학년도 12개월 계산 결과와 서로 다른 그룹을 축소 표시한다. 표지 사진·연도·정보 영역, 월력 앞면의 헤더/달력 영역, 뒷표지의 주 요소·사진·정보 영역, 학교 상징·학교 소개의 개체 좌표, 연력·학사일정·Yearly Plan의 제목/12개월 본문 영역은 설정 카드와 실제 생성 개체가 공통 계산 함수를 사용하며, 표준형 260×180과 와이드형 297×148의 재단 크기를 입력으로 받는다. 카드의 외형 비율도 실제 재단 크기를 따른다. 학교 소개의 선택형 교표·교훈은 실제 선택 수에 맞게 자리 잡는다. 월력 뒷면은 기존 `ACDLAIDesignSettings.monthBackLayouts`가 카드와 편집 개체 생성에 함께 사용되는 것을 확인했고 카드 비율을 재단 크기에 맞췄다. 뒷표지 내부 학교 정보도 카드와 실제 개체가 공통 계산한다. 월력 뒷면의 생성 좌표를 기록해 이후 수동 이동·크기 변경을 설정 저장 시 유지하며, 선택한 경우에만 새 대표 배치를 재적용한다. 기준 좌표가 없는 이전 생성 개체는 수동 조정 여부를 알 수 없어 위치를 보수적으로 유지한다. **월력 앞면의 사진 상세 구도, 세로형 구도, 실제 저장·재열기와 Preview 검증은 아직 남아 있다.** 연력은 독립 물리 면이 아닌 안쪽면·간지의 선택 용도로 규칙에 포함한다. 이번 변경까지 `npm run build`가 통과했고 Studio 검사 563개 및 런타임 검사 15개가 통과했다.

## 1. 면의 위치와 용도를 따로 결정한다

1. 달력 유형의 면 구성 규칙으로 **실제 물리 면**을 먼저 확정한다. 표지, 표지 안쪽면, 선택한 앞·뒤 간지의 앞면과 뒷면, 12개월의 월력 앞·뒷면, 뒷표지 안쪽면, 뒷표지다. 간지 매수와 첫 월력 뒷면 공유 옵션에 따라 실제 면 목록은 달라진다. 번호나 `n면`은 결과이지 용도가 아니다.
2. 표지·월력 앞/뒤·뒷표지는 본래 역할을 가진다. **표지 안쪽면, 각 간지 면, 뒷표지 안쪽면**에는 실제 면마다 연력·학교 상징·학교 소개·학사일정·Yearly Plan·사용자 정의·빈 페이지 중 하나의 **페이지 용도**를 선택한다. 위치가 같아도 선택 용도가 바뀌면 개체·배치 규칙을 바꾼다.
3. 각 면은 `물리 면 ID + 선택 용도 + 구성 형태 + 개체 + 대표 배치 + 실제 배치 좌표`를 연결해 저장한다. 첫 월력 뒷면 공유 면은 월력 뒷면이라는 실질 역할을 명시하고, 독립된 간지/안쪽면 배치를 동시에 적용하지 않는다.
4. 선택 용도 안에서만 `구성 형태 → 기본/선택 개체 → 유효한 대표 배치` 순으로 진행한다. 형태를 바꿀 때 고유의 핵심 개체와 첫 추천 배치를 제안한다. 기존 면의 수동 편집 개체는 조용히 삭제하거나 이동하지 않는다.

## 2. 표지·월력·뒷표지

## 3. 안쪽면과 간지의 용도별 세부 설정

아래 용도는 **표지 안쪽면, 실제 존재하는 간지 각 면, 뒷표지 안쪽면**에 독립적으로 지정할 수 있다. 특정 위치에 특정 용도를 고정하지 않는다. 다만 한 물리 면에는 한 용도만 적용한다.

| 선택한 용도 | 핵심·기본 개체 | 선택 개체와 자료 | 추천 대표 배치의 실질 차이 |
| --- | --- | --- | --- |
| **연력** | 학사연도 연도 표시 + 3월~이듬해 2월의 **12개월 실제 날짜 월력** | 교표, 월 표시 방식, 요일/격자 표시 | 열린 12개월 격자 / 월별 카드 / 3개월씩 세로 그룹 / 4개월씩 가로 그룹. 개체는 12개월 연력 하나여도 내부 배열·경계·그룹이 바뀐다. 연력은 연간 월력이라는 *기능 정보*이므로 일반 사진·텍스트 카드 배치를 보여주지 않는다. |
| **학교 상징** | 제목 + 등록된 교훈·교가·교목·교화·교표 중 **실제로 사용할 항목 1개 이상** | 각 상징의 이미지·이름·설명; 교가는 악보 이미지와 곡 정보 | 교가가 있으면 악보의 읽을 수 있는 큰 영역을 우선하고 다른 상징을 별도 영역에 둔다. 교가가 없으면 상징의 수에 맞춰 개별 카드/열린 편집 구도를 추천한다. 카드형과 구분선형은 실제 표시 방식까지 미리보기로 구분한다. 자료가 없을 때 빈 교가 박스를 만들지 않는다. |

| **학사일정** | 제목 + 학사연도 12개월에 연결된 일정 목록 | 필요한 경우 설명·범례 | 열린 12개월 배열 / 월별 카드 / 3개월씩 세로 그룹 / 4개월씩 가로 그룹. 일정 데이터가 비어도 12개월 틀을 유지하고 ‘등록된 일정 없음’을 편집 화면에서 구분한다. 페이지 이름과 월 표시는 일정 데이터의 학년도와 연결한다. |

연력과 Yearly Plan은 모두 12개월을 보여주지만 전자는 **날짜를 읽는 달력**, 후자는 **내용을 적는 칸**이다. 학교 상징은 사진 한 장을 크게 보여주는 학교 소개와 달리 악보·상징 설명의 가독성이 우선이다. 학사일정은 일정 데이터가 핵심이므로 날짜 월력이나 Yearly Plan의 빈칸으로 대신하지 않는다.

## 4. 추천·실제 배치에 적용할 공통 규칙

1. **하나의 배치 계산 결과**에서 설정 카드 그림, AI 생성용 보호 영역, 편집 개체 좌표, 저장 후 재열기, 검토용 PDF의 위치를 얻는다. 카드 전용 좌표와 편집 화면 전용 좌표를 따로 두지 않는다.
2. 입력은 물리 재단 크기·안전 영역, 용도/구성 형태, 실제 선택 개체와 개수, 읽기 우선순위, 자료 유무다. 내부는 mm 기준 최소 크기와 간격을 검사하고, 최종 좌표를 페이지 비율로 저장한다. 표준형에서 성립하지 않는 조합을 ‘추천’으로 표시하지 않는다.
3. 사진·교표·악보는 크롭/contain 규칙을 구분한다. 연력·일정·계획표·메모의 읽기/쓰기 영역에 필요한 크기를 먼저 확보한다. 그 뒤 사진과 장식 영역을 배정한다. 가려지는 정보, 개체 겹침, 페이지 밖 돌출을 검사한다.
4. 추천은 선택한 구성의 **실제로 다른 구도**만 보여준다. 숨긴 선택지는 이유를 표시한다. 그림은 실제 개체와 기능적 스타일(월별 카드·구분선·그룹)을 반영한다. 자료가 비어 있는 것과 개체 자체를 선택하지 않은 것은 구분한다.
5. 페이지 설정 저장은 새 초안의 기본 개체 배치를 확정한다. 이후 편집자의 수동 조정이 시작된 면에는 설정 변경의 영향 범위를 보여주고, 기존 위치 유지/새 배치 재적용을 명시적으로 고른다. 12개월 공통 배치와 한 달만 수정한 예외를 구분한다.
6. 생성 배경은 같은 보호 영역을 입력으로 받아 사진·월력·메모를 가정한 가짜 프레임을 그리지 않게 한다. 이미 만들어진 배경과 개체의 축이 맞지 않으면 배경을 재생성할지 편집자가 수동 조정할지를 구분한다.

## 5. 구현·검증 순서

1. 표준형 260×180mm의 용도별 핵심/기본/선택 개체, 유효 배치 규칙을 설정 화면에 적용한다. 물리 면과 용도 설정을 분리한다.
2. 미리보기와 실제 개체 생성의 좌표 계산을 하나로 합친다. 용도별 기능적 표현(연력, 상징, 학사일정, 계획표)을 보인다.
3. 표준형의 대표 조합을 실제 편집 화면에서 확인한다. 각 용도마다 유형 변경 → 개체 선택 → 배치 선택 → 저장 → 재열기 → 검토용 PDF의 동일성을 검사한다. 12개월 면은 적어도 첫 달·중간 달·다음 해 2월 및 전체 적용 개수를 확인한다.
4. 같은 규칙에 와이드형의 실제 크기와 비율을 넣어 다시 계산한다. 세로형은 정보의 읽기 순서와 주요 구도를 별도로 설계하되 면 용도·핵심 개체·검증 규칙은 공유한다.

기존 게시된 Package를 일괄 변경하지 않는다. 새 초안에 적용하고 기존 수동 편집본은 명시적인 재배치 선택이 있을 때만 바꾼다.
