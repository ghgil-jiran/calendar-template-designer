# 벽보형 샘플 A · 플라워 1면형

사용자가 선택한 수채화 배경을 원본 PNG 그대로 보존한다. A2 세로 420×594mm, 도련 3mm 포함 426×600mm PDF에 배치한다. 원본 1055×1491px의 유효 해상도는 약 63dpi이며, PDF 포장은 해상도를 높이지 않는다. 인쇄 승인·PDF/X 적합성을 표시하지 않는다.

학교명·연도·슬로건은 상단 중앙, 12개월 월력은 x5/y16/w90/h74%의 3열×4행, 교표·학교명·영문명·주소·연락처는 하단 중앙에 연결 개체로 배치한다. 학교 사진 프레임은 이 디자인에 포함하지 않는다. 교표는 contain 및 분리형 학교명 그룹을 사용한다.

달력 유형 → 벽보형 → 1페이지형(420×594mm) → **샘플 A · 플라워 1면형 만들기**에서 관리자 세션으로 등록한다. `/api/poster-sample`의 `floral-a` 변형은 배경 PDF 원본을 기존 그래픽 PDF 저장소에 등록하고, 별도의 stableKey `poster-sample-a-floral-2027`를 가진 새 초안으로 저장한다. 기존 1면형 샘플과 탁상형 샘플 A는 수정하지 않는다. 이미 등록된 stableKey는 다시 만들거나 덮어쓰지 않는다. 중간 실패는 같은 버튼으로 재개할 수 있다.

달력 데이터와 학교 정보는 기존 샘플 C의 저장된 자료에서 가져오고, 출력은 기존 공통 Runtime과 원본 PDF 합성 경로를 사용한다. 등록 완료 후 실제 편집 화면에서 배치와 긴 학교명·많은 일정의 넘침을 확인하고 저장해 대표 이미지를 갱신한다. 게시 및 Production 배포는 별도이다.

코드 검사와 Preview READY만으로 등록 완료·화면 확인·실물 인쇄 또는 Acrobat 통과를 주장하지 않는다.

기존 샘플은 같은 카드의 **샘플 A · 목록형으로 업데이트**에서 최신 저장 버전을 확인하고 새 초안 버전으로 저장한다. 배경 원본·학교 자료·일정·위치·크기·월별 글자 설정은 보존하고, 일정·공공 정보 위치와 목록 높이(50%), 포함 정보 기본값만 변경한다. 이미 v2이면 반복 저장하지 않는다. 업데이트 뒤 편집 화면에서 확인하고 검토 완료로 다시 저장한다.
