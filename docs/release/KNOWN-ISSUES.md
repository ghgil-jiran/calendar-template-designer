# Known Issues — v1.0 Beta

- 실제 편집 화면은 아직 Legacy Renderer를 사용한다. Runtime Renderer는 미리보기·검증·출판 모델에 사용된다.
- PublishingRenderer는 SVG를 생성하며, PDF/PNG 바이너리 생성은 아직 포함하지 않는다.
- Collision Engine은 충돌을 진단하지만 개체를 자동 이동시키지 않는다.
- 텍스트 Auto-fit은 기본 규칙이며 브라우저 폰트 메트릭과 완전한 인쇄 조판은 아직 동일하지 않을 수 있다.
- CalendarType Manager, Master 전체 적용, 이미지 업로드, 저장·불러오기는 브라우저 수동 회귀 검사가 필요하다.
- 로컬 파일 실행 환경에서는 일부 브라우저 보안 정책에 따라 파일 접근 기능이 제한될 수 있다.
