# Calendar Template Designer v1.0 Beta RC2

## RC1 이후 수정

- 새 브라우저에서도 CalendarType 기본 정의를 localStorage에 자동 초기화
- 첫 실행부터 유형별 복수 크기 프리셋 표시
- 첫 실행부터 유형별 시작 템플릿 필터 적용
- 제품명과 버전 표기를 `Calendar Template Designer v1.0 Beta RC2`로 통일
- 런타임 릴리스 메타데이터 `window.ACDL_RELEASE` 추가

## 핵심 회귀 시나리오

1. Designer Studio 진입
2. 달력 유형 관리 열기
3. 탁상형 크기 3종 확인
4. 추천 크기 변경 후 저장
5. 닫기 후 Designer Studio 복귀
6. 새 템플릿에서 크기와 시작 템플릿 확인
