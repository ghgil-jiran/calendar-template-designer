# Calendar Template Designer v1.0 Beta RC1

## 구현 완료

- Type Manager 닫기 동작을 Designer Studio 복귀로 명시
- CalendarType이 여러 Size Preset을 소유하도록 확장
- Size Preset 추가·삭제·추천 지정 UI
- CalendarType별 Starter Template 관리
- 새 템플릿 설정의 용어를 `시작 템플릿`으로 통일
- CalendarType 설정에서 새 템플릿 크기 및 시작 템플릿을 동적으로 제공

## 검증 상태

- JavaScript 구문 검사 수행
- 정적 DOM 및 이벤트 연결 검사 수행
- 실제 브라우저 상호작용 QA는 자동 브라우저 테스트 결과와 사용자 확인을 함께 기록해야 함
