# 공통 그래픽 라이브러리 메뉴 정리 · 2026-10-13

- 사용자 요청: 전체 자산 / 그래픽 패키지 / 자산 추가 3개 상단 메뉴.
- 자산 추가의 이미지 추가 / 새 테마 만들기 2개 하위 메뉴. 업로드 및 테마 작업 화면에 전체 자산으로 돌아가기 버튼.
- 기본 화면은 저장된 이미지/테마 소재/패키지 연결 이미지를 함께 표시. 이름·태그·테마 검색, 종류 및 주제 카테고리 필터. 주제 분류 제목과 기본 테마 드롭다운 제거.
- 명시적 주제 분류 없는 소재는 소속 테마 주제 분류로 검색. 라이브러리 재진입 시 기본 전체 조건으로 시작.
- 기존 이미지, 테마, 패키지, 원본 및 메타데이터 보존. 데이터 삭제/이전 없음.
- 개별 이미지 생성 진입 메뉴와 자산의 standalone 변형 만들기 제거. 패키지 편집에 필요한 내부 생성기는 유지.
- 새 테마 만들기 작성 내용은 메뉴 이동 시 보존. 목록으로 돌아가기에서 저장 안 된 변경 확인 후 초기화.
- SVG 독립 배경도 선택 모드에서 기존 이미지 소스로 배경 적용 가능. SVG에는 래스터 DPI 안내 제외.
- 검증: 전체 build / Studio 860개 통과. 3개 메뉴, 2개 추가 방법, 목록 복귀, 카테고리 검색, 기존 자산 보존 및 패키지 편집 회귀 검증.
- 로그인된 실제 관리자 화면의 시각 검증은 미실시. Preview만 배포.
