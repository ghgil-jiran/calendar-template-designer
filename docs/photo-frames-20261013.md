# 사진 프레임 확장

- 기존 8종과 신규 12종, 총 20종을 공통 `photo-frame-model.js`에서 정의한다.
- 신규: 캡슐, 팔각형, 모서리 절삭, 대각 둥근, 상단 둥근, 하단 아치, 물방울, 잎사귀, 비대칭 곡선, 티켓, 물결, 둥근 꽃잎.
- 공통 라이브러리의 사진 프레임 주제로 개별 자산 등록한다. 프레임 추가는 사진을 담는 image-frame 개체를 생성한다. 기존 사진 프레임 추가 창과 스타일 선택에서도 같은 20종을 제공한다.
- 곡선 정의를 비율 좌표로 샘플링하여 사진 자르기 영역을 구성한다. SVG 윤곽은 같은 원본 경로를 사용한다. 테두리 두께 0을 지원한다.
- 템플릿 원본의 frameType을 Runtime 메타데이터로 전달하고 사용자 서비스도 같은 정의로 렌더링한다.
- 저장된 사진 맞춤/확대/이동과 교체 권한은 기존 흐름을 사용한다.
- 설치 마커는 재등록/삭제한 자산의 자동 복원을 방지하고 중단된 등록은 기존 자산을 보존하며 이어간다.
- 형태별 SVG 렌더 검토, 공통 좌표/테두리 검사, 설치 재시도/보관/삭제 회귀 검사 통과. 로그인 실화면과 최종 인쇄 PDF/CMYK는 미검증.

검증: 에디터 스타일 검사·패키지 검사·Studio 865개·제품 상호작용 검사 통과. 사용자 서비스 Next 빌드 통과.
