# [학사달력] 탁상형 검토 02 - 이미지 미니월력 완성 기준

## 목표

샘플 달력 3번 PDF를 기준으로 `desk-sample-3`을 표지부터 뒷표지까지 총 28면의 완성된 검토 템플릿으로 만든다. 단순히 월력 선 모양만 비슷하게 만드는 것이 아니라 실제 제품의 이미지 구성, 정보 위계, 앞뒤 면 흐름까지 최대한 가깝게 재현한다.

## 고정된 면 구성

1. 1면: 표지
2. 2면: 연력
3. 3면: 학교 상징·정보 간지
4. 4~27면: 2028년 3월부터 2029년 2월까지 월별 이미지 면과 월력 면 12쌍
5. 28면: 뒷표지

## 이번 완성 범위

- 표지: 샘플 3번의 사진·연도·학교 정보 위계와 배경 구성
- 연력: 12개월 연간 달력과 제목·학교 정보 배치
- 간지: 교표, 교훈, 교화, 교목, 교가 등 학교 상징 정보 구성
- 월별 이미지 면: 한 장짜리 사진 대체가 아니라 샘플의 이미지 프레임·콜라주·캡션 구성을 재현
- 월력 면: 샘플 3 계열의 독립 요일 캡슐, 세로선 없는 열린 가로선, 전후월 미니월력과 일정 표시
- 뒷표지: 학교명·교표·연락처·주소·웹사이트와 샘플에 가까운 배경 구성
- 28면 물리 순서, 앞뒷면 관계, 화면 미리보기와 검토 PDF의 일치

## 월력 원칙

- 샘플 3과 샘플 6은 같은 표의 선 표시 옵션이 아니라 독립된 프리셋이다.
- 5×7·6×7은 날짜 배치 구조이며 디자인 유형이 아니다.
- 월 제목, 요일, 날짜 영역의 세로 비율을 먼저 확보하고 겹침을 예외 CSS로 덮지 않는다.
- 기간 일정은 공통 일정 계약을 따르되 열린 가로선과 셀 간격에 맞춰 표현한다.
- 미니월력은 빈 날짜 셀의 고정 예약 영역 안에서만 표시한다.

## 데이터와 이미지 원칙

- 템플릿에는 사용자가 교체할 수 있는 완성도 높은 샘플 이미지를 기본 배치한다.
- 사용자 업로드 이미지는 자동 배치하지 않고 선택한 이미지 개체만 교체한다.
- 학교명, 영문 학교명, 연도, 교표, 학교 전경, 학교 상징과 연락처는 기존 Binding·Dataset 계약을 사용한다.
- 연도 기본값은 숫자만 사용한다. `2028년`이 필요하면 별도 대체 텍스트로 표현한다.

## 완료 검사

1. 28면 전체가 정해진 순서와 역할로 생성된다.
2. 표지·연력·간지·월별 이미지·월력·뒷표지가 샘플 3번과 한눈에 같은 계열로 보인다.
3. 2028년 3월~2029년 2월, 5행·6행, 전후월 미니월력이 정상이다.
4. 기간 일정·단일 일정·일정 과밀 표시가 기존 공통 계약을 유지한다.
5. 샘플 이미지 교체, 저장, 재열기, 현재 면/같은 Master 적용이 정상이다.
6. 전체 미리보기와 28면 검토 PDF에 잘림·겹침·빈 면·면 순서 오류가 없다.
7. 전체 build와 Studio 회귀검사를 통과한다.

## 2026-09-03 구현 진행 상태

- `desk-sample-3` 문서 버전을 2로 올리고 기존 버전 1 초안의 안전한 자동 갱신 경로를 추가했다.
- 샘플 PDF에서 분리한 학교·학생·계절·수업·졸업 사진 15개를 웹용 샘플 자산으로 최적화했다.
- 12개 이미지 면은 샘플 순서에 맞춰 3분할 콜라주 5면과 큰 단일 사진 7면으로 구분한다.
- 모든 이미지 면은 현재 월·이전 월·다음 월 미니월력 공통 Master를 유지한다.
- 표지에는 학교 전경과 학생 보조 사진을 함께 배치하고, 연력의 `CALENDAR`와 연도는 서로 독립된 개체로 구성했다.
- 사용자가 월별 이미지를 등록하면 데이터 연결 이미지가 샘플 자산보다 우선한다.
- 전체 build, Studio 189개 테스트, 인라인 스크립트 23개 검사를 통과했다.

### 상세 표현 보강 - 문서 버전 3

- PDF에서 추출한 CMYK 이미지의 반전 원인을 색공간 변환으로 확인하고, 15개 자산을 정상 sRGB WebP로 다시 만들었다.
- 연력은 카드형 테두리를 제거하고 샘플의 `1 JAN` 형식, 4열×3행, 간결한 숫자 중심 표현으로 보강했다.
- 월별 이미지 면은 흰색 바탕을 사용하며, 현재·이전·다음 월력의 카드 테두리와 불필요한 요일 머리글을 제거했다.
- 월력 면 상단에는 왼쪽 교훈·슬로건과 오른쪽 교표를 12개월 공통 Master 개체로 추가했다.
- 월력 영역은 상단 정보와 중앙 월 제목이 같은 높이에서 공존하도록 제목·요일·날짜 영역 비율을 `16:5:79`로 조정했다.
- 뒷표지 하단 정보 패널에 학교명과 홈페이지 Binding을 보강했다.
- 버전 2 초안은 이미지와 사용자 학교 데이터를 유지하면서 버전 3 상세 표현으로 자동 갱신한다.

다음 시각 검토는 전체 미리보기와 28면 검토 PDF에서 표지, 연력, 간지, 12개 이미지·월력 쌍, 뒷표지 순으로 진행한다. 검토 승인 전에는 Published Package로 승격하지 않는다.

- `desk-academic-standard@1.4.0` Published Package를 덮어쓰지 않는다.
- `[학사달력] 탁상형 검토 01`의 샘플 6 계열 디자인을 함께 변경하지 않는다.
- 사용자 서비스 화면을 다시 만들거나 사용자 업로드 이미지를 자동 배치하지 않는다.
- 디자인 검토가 끝나기 전에 새 Package를 Published로 승격하지 않는다.
