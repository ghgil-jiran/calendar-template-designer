# 템플릿 카드 이름·설명 규칙

## 목적

달력 템플릿 에디터와 학사달력 에디터 서비스에서 같은 템플릿을 같은 이름과 정보 순서로 표시한다. 내부 Package 버전은 이름과 분리해 보조 정보로 유지한다.

## 표시 이름

`[달력 분야] 달력 유형 표준|검토 NN - 특징`

- 현재 적용 분야: `학사달력`
- 이후 확장 분야: `개인달력`, `기업달력`(이번 작업에서는 카드에 추가하지 않음)
- `표준`: 사용자 서비스에 최종 배포된 템플릿
- `검토`: 제작 중이거나 내부 검토 중인 템플릿
- 검토본이 최종 배포되면 같은 번호를 유지하고 `검토`만 `표준`으로 바꾼다.
- `NN`은 두 자리 번호로 표시한다.

예시:

- `[학사달력] 탁상형 검토 01 - 월별 플래너`
- `[학사달력] 탁상형 표준 02 - 월별 이미지`

## 설명

`총 NN면 · 표지 N면 · 간지 N면 · 월력 N면 · 뒷표지 N면 — 세부 구성 / 세부 구성`

- 앞부분은 실제 출력 면수와 영역별 면수다.
- 마지막 부분은 표지 뒷면, 간지, 월력 뒷면, 뒷표지의 대표 구성을 출력 순서에 가깝게 표시한다.
- 합계가 `총 NN면`과 맞아야 한다.

탁상형 28면 예시:

`총 28면 · 표지 1면 · 간지 2면 · 월력 24면 · 뒷표지 1면 — 연력 / 학교상징 / 월별 플래너`

## 카드 정보 순서

1. 대표 미리보기
2. `표준` 또는 `검토` 상태
3. 통일된 표시 이름
4. 내부 버전(`Package ID@version` 또는 `vN`)
5. 면 구성 설명
6. 특징 태그
7. 해당 서비스의 실행 버튼

버튼 문구와 카드 색상은 각 서비스의 역할과 기존 UI를 유지한다.
