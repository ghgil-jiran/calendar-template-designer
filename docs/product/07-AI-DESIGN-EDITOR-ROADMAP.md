# AI 디자인 에디터 v1.1 기획안

- 모듈: 달력 템플릿 에디터 v1.3의 하위 기능
- 목표 모듈 버전: `AI 디자인 에디터 v1.1`
- 문서 버전: `0.2.0`
- 최초 작성일: 2026-09-04
- 상태: 방향 확정 · 단계별 상세화 예정

## 1. 문서의 역할

이 문서는 달력 템플릿 에디터 안에서 AI가 페이지 구조에 맞는 디자인 요소와 배치안을 생성하고, 디자이너가 이를 선택·부분 재생성·적용·편집·저장해 실제 템플릿으로 완성하는 `AI 디자인 에디터 v1.1`의 장기 기준이다. 한 번에 최종 사양을 확정하지 않고 실제 사용 결과, 디자이너 피드백, 화면 검토와 인쇄 결과를 반영해 문서와 모듈을 독립적으로 개정한다.

달력 템플릿 에디터의 저장·편집·버전 관리 기능은 그대로 유지한다. AI 디자인 에디터는 그 안에서 디자인 콘셉트, 페이지별 독립 자산, 기존 개체의 스타일, 배치안과 새 개체 후보를 생성·제안하는 하위 모듈이다. 샘플 수집·분석은 이 모듈의 목적이 아니라 프롬프트와 스타일 규칙을 개선하기 위한 참고 과정이다.

## 1.1 정식 진입 흐름

AI 디자인 생성은 편집 화면 상단에서 임의로 여는 부가 도구가 아니다. 새 템플릿 제작의 단계별 설정 안에 들어간다.

`새 템플릿 만들기 → 상품·페이지 구성 선택 → 템플릿 설정 → AI 디자인 생성 → 시안 선택 → AI 디자인 적용 초안 생성 → 편집 화면에서 세부 조정`

`템플릿 설정`은 기본 설정, 학교 정보 및 에셋, 색상 테마, 폰트 테마, Master, 일정 분류, 출력 설정, 그래픽 라이브러리의 정보를 먼저 확정한다. `AI 디자인 생성`은 이 정보를 종합해 전체 디자인 세트 또는 선택한 페이지 역할의 시안을 만든다. 선택 결과는 원본을 덮어쓰지 않고 별도 초안으로 만든 뒤 기존 편집 화면에서 조정한다.

## 1.2 독립 모듈과 버전 관리

`AI 디자인 에디터 v1.1`은 `달력 템플릿 에디터 v1.3` 안에서 동작하지만 다음 항목은 본체와 분리해 독립적으로 버전 관리한다.

- AI 디자인 모듈
- 프롬프트 세트
- 디자인 스타일 규칙
- 페이지 역할별 생성 조건
- 디자인 품질 평가 기준
- 참고 샘플에서 추출한 규칙과 평가 결과

프롬프트나 스타일 규칙의 새 버전은 기존 Published Package, 기존 AI 디자인 적용 초안과 기존 디자인 세트를 자동 변경하지 않는다. 모든 생성 세션과 결과에는 실제로 사용한 각 규칙의 ID·버전, 생성 범위, 상품 규격, 페이지 역할, 출력 조건과 생성 시각을 기록한다. 버전 운영의 세부 정본은 `08-AI-DESIGN-EDITOR-FUNCTION-STRUCTURE.md`에서 관리한다.

## 2. 제품 전략

초기부터 완성 템플릿을 많이 제작하지 않는다. 사용자 서비스에는 두 개의 독립 축을 조합해 충분한 선택 폭을 제공한다.

- 학교에 어울리는 디자인 스타일: 초기 3~4종
- 월력과 월력 뒷면을 포함한 구성 타입: 초기 4~5종
- 사용자에게 보이는 조합: 약 12~20종

예를 들어 같은 `사계절 일러스트` 스타일을 박스형 월력, 열린 가로선 월력, 이미지+미니월력형, 플래너형 구성에 각각 적용할 수 있다. 이후 스타일이나 구성 타입 하나만 추가해도 전체 선택지가 함께 늘어난다.

완성 템플릿은 검증된 `디자인 스타일 × 구성 타입 × 상품 규격` 조합을 저장한 결과물로 본다. 스타일과 구성을 처음부터 하나로 묶어 중복 제작하지 않는다.

## 3. 초기 디자인 스타일 후보

첨부된 외부 서비스 표지 샘플에서는 사진 중심, 계절 콜라주, 타이포그래피 중심, 기업형 미니멀, 귀여운 캐릭터, 부드러운 일러스트, 학교·기관 브랜드 중심 등 서로 다른 조형 언어가 확인됐다.

초기 후보는 다음 범위에서 3~4종을 선정한다.

1. 학교 사진 중심의 단정한 브랜드형
2. 사계절 변화가 이어지는 자연·일러스트형
3. 학생 친화적인 귀여운 캐릭터형
4. 타이포그래피와 도형 중심의 현대적 미니멀형

스타일 이름만으로 생성하지 않는다. 각 스타일은 색상, 장식 밀도, 사진 사용 방식, 글자 위계, 여백, 계절 변화, 학교급 적합성, 금지 표현을 포함한 별도 규칙 세트로 관리한다.

## 4. 초기 구성 타입 후보

구성 타입은 날짜 계산과 콘텐츠 역할을 소유하고, 디자인 스타일은 그 위에 시각 표현을 입힌다.

1. 박스형 월력 + 월간 목표·할 일 플래너
2. 열린 가로선 월력 + 이미지·현재/전후월 미니월력
3. 이미지 중심 월력 + 띠 월력·메모
4. 일정 강조 월력 + 위클리 플래너·체크리스트
5. 미니멀 월력 + 넓은 학교 행사·메모 영역

월 표시, 요일, 날짜 격자, 연력, 띠 월력, 미니 월력, 위클리 메모 등은 서로 교체 가능한 편집 개체 또는 복합 개체로 유지한다.

## 5. AI가 만드는 것과 만들지 않는 것

AI는 페이지 전체를 한 장의 완성 이미지로 굽지 않는다. 결과는 다음 네 부분으로 나눈다.

1. 배경·패턴·일러스트·장식·사진 프레임 등의 이미지 자산
2. 텍스트·월력·연력·격자·선·도형 등 편집 가능한 개체 구성
3. 위치·크기·정렬·겹침·안전 영역을 포함한 배치 설계
4. 색상·서체·선·여백·투명도·월별 변형을 포함한 스타일 규칙

연도, 학교명, 월·요일·날짜, 학사일정, 주소와 연락처는 AI 이미지 안에 고정하지 않는다. 기존 데이터와 연결되는 편집 개체로 유지한다. 수채화, 사진, 복잡한 질감은 고해상도 이미지로 유지하고, 격자·단순 프레임·선·도형·텍스트는 벡터 또는 텍스트로 유지한다.

## 6. 생성 범위와 페이지별 디자인 대상

간지 포함 여부에 따라 실제 페이지 수는 달라진다. AI 디자인 생성은 고정된 페이지 번호보다 다음 역할을 기준으로 동작한다.

- 표지: 학교 사진, 연도, 학교명, 교표와 표지 장식
- 표지 뒷면: 연력 또는 학교 상징
- 앞간지 앞·뒷면: 선택형 학교 콘텐츠
- 월력: 월 표시, 요일, 날짜 격자, 일정 강조와 월별 장식
- 월력 뒷면: 이미지, 현재/전후월 미니월력, 띠 월력, 위클리 메모, 체크리스트
- 뒷간지 앞·뒷면: 선택형 학교 콘텐츠
- 뒷표지: 학교 전경, 주소, 연락처, 교표와 정보 위계

생성 범위는 `선택 영역`, `현재 페이지`, `같은 역할의 페이지`, `월별 페이지 전체`, `템플릿 전체 디자인 세트`를 지원한다. 전체 세트는 표지부터 뒷표지까지 같은 색상·조형 언어를 유지하면서 페이지 역할과 월별 계절 변화를 구분한다. 초기에는 2~4개 시안을 비교하며 실제 역할 수와 대표 미리보기 수는 기능 구조 기획에서 확정한다.

## 7. 프롬프트와 스타일 규칙의 독립 버전 관리

좋은 디자인은 모델에 `예쁘게 만들어 달라`고 요청하는 것으로 확보되지 않는다. 프롬프트는 다음 조건을 포함한 디자인 규칙 세트로 관리한다.

- 참고 샘플에서 선택한 디자인 특징과 피해야 할 모방
- 학교급, 사용 목적과 학교 브랜드의 분위기
- 장식 밀도와 여백의 최소 기준
- 월력 숫자·학사일정·학교 정보의 가독성 우선순위
- 사진과 교표를 변형하지 않는 영역
- 표지부터 월력·뒷표지까지 이어지는 통일 규칙
- 월별 변화와 사계절 표현의 강도
- 화려함, 색상 수, 패턴, 그림자, 캐릭터 수의 상한
- 도련·안전 영역, 이미지 해상도와 인쇄 색상 조건
- 생성하지 않아야 할 텍스트, 날짜, 로고와 장식 유형

각 스타일 규칙은 코드와 분리해 다음 정보를 가진다.

- `styleProfileId`
- `styleProfileVersion`
- 대상 상품·학교급·페이지 역할
- 공통 지시와 페이지별 지시
- 금지 조건
- 참고 샘플 분석 기록
- 품질 평가 결과와 변경 이력

생성된 시안에도 사용한 스타일 규칙 버전, 모델, 출력 크기, 품질 설정과 참고 자산을 기록한다. 이전 결과를 재현하거나 새 프롬프트와 비교할 수 있어야 한다.

## 8. 생성과 검토 흐름

1. `새 템플릿 만들기`에서 상품 규격과 페이지 구성을 선택한다.
2. `템플릿 설정`에서 학교 자료, 색상·폰트, Master, 일정 분류, 출력 조건과 그래픽 자산을 정한다.
3. `AI 디자인 생성`에서 적용 범위와 디자인 조건을 정한다.
4. 전체 세트 또는 선택한 역할의 디자인 시안 2~4개를 생성한다.
5. 전체·페이지별·요소별 시안을 비교한다.
6. 마음에 들지 않는 페이지나 요소만 다시 생성하거나 다른 시안의 요소로 교체한다.
7. 선택된 결과를 독립 이미지 자산, 기존 개체 스타일, 배치안과 사용자 지정 개체 후보로 적용한다.
8. 적용 전후를 비교하고 현재 템플릿을 덮어쓰지 않은 새 `AI 디자인 적용 초안`으로 저장한다.
9. 기존 편집 화면에서 위치·크기·색상·투명도·겹침 순서를 조정한다.
10. 화면·Runtime·저장·PDF·출력 품질 검사를 통과한 결과만 재사용 가능한 디자인 세트로 저장한다.
11. 검증된 디자인 스타일과 구성 타입의 조합만 사용자 서비스에 제공한다.

## 9. 디자인 품질 평가 기준

모든 시안은 다음 기준으로 평가한다.

- 학교 달력으로 자연스럽고 대상 학교급에 적합한가
- 보기 좋지만 내용보다 장식이 앞서지 않는가
- 학교명, 연도, 월·요일·날짜와 일정이 잘 읽히는가
- 표지, 연력, 월력, 월력 뒷면과 뒷표지가 한 계열로 보이는가
- 12개월의 변화가 단조롭지도, 서로 다른 템플릿처럼 보이지도 않는가
- 사용자가 학교 사진과 내용을 바꿔도 균형이 유지되는가
- 실제 인쇄에서 색상, 작은 글자, 얇은 선과 이미지 품질이 안전한가

평가 결과는 스타일 규칙의 다음 버전에 반영한다. 프롬프트 개선 자체를 AI 디자인 에디터의 지속 작업으로 관리한다.

## 10. 새 개체와 옵션의 축적

AI 시안에서 `Yearly Check List`, 새로운 띠 월력, 새로운 날짜 격자처럼 기존에 없는 표현이 발견되면 즉시 전체 기본 옵션으로 공개하지 않는다.

1. 해당 템플릿의 사용자 지정 실험 옵션으로 추가
2. 데이터 연결과 편집 패널 지원 확인
3. 저장·재열기·Runtime·미리보기·PDF 검사
4. 관리자 검토와 이름·범위 확정
5. 공통 기본 옵션 또는 정식 복합 개체로 승격

이미지로만 흉내 낼 수 있는 표현과 실제 편집 개체로 만들 가치가 있는 표현을 구분한다.

## 11. 인쇄 품질 적용 시점

인쇄 조건은 설계 초기부터 적용하고 최종 CMYK 변환은 출력 단계에서 한 번 수행한다.

### 구성 단계

- 제작·재단 크기, 도련, 안전 영역과 최소 선·글자 기준 적용
- 인쇄소 ICC 프로파일과 색상 정책 지정
- AI 자산이 들어갈 실제 크기와 필요한 해상도 계산

### 디자인 생성·편집 단계

- AI 생성 RGB 고화질 원본 보존
- 웹용 미리보기와 인쇄용 원본 분리
- 텍스트·격자·단순 도형은 벡터 유지
- RGB와 예상 CMYK 결과를 비교하는 소프트 프루프 제공
- 색역, 유효 해상도, 얇은 선, 작은 글자와 투명 효과 경고

### 디자인 승인 후

- 선택한 자산만 최종 크기와 품질로 확정
- 필요한 단순 장식을 벡터 개체로 재구성
- 실제 배치 크기 기준 해상도와 잘림 검사

### 최종 출력 단계

- 래스터 이미지의 지정 ICC 변환
- 텍스트와 벡터 보존, 폰트와 출력 의도 처리
- PDF/X-4 생성
- Trim/Bleed, 페이지 수·순서, Binding, DPI와 Preflight 검사
- 대표 조합의 실제 교정 인쇄

디자인 승인은 RGB 화면에서 예뻐 보이는 상태가 아니라 CMYK 예상 결과와 출력 위험을 확인한 상태로 정의한다.

## 12. 버전 운영

- 달력 템플릿 에디터 본체와 AI 디자인 에디터 모듈 버전을 분리한다.
- 프롬프트 세트, 스타일 규칙, 페이지별 생성 조건과 평가 기준도 각각 독립적으로 갱신할 수 있어야 한다.
- 기존에 생성된 템플릿은 사용한 스타일 규칙 버전을 계속 보존한다.
- 스타일 규칙 업데이트가 기존 Published Package를 자동 변경하지 않는다.
- 생성 결과에는 모듈·프롬프트·스타일·페이지 규칙·평가 기준의 실제 사용 버전을 함께 기록한다.
- 큰 방향 변경은 이 문서의 minor 버전을, 오탈자·설명 보완은 patch 버전을 올린다.
- 구현 계약이 확정되면 별도 Schema 버전을 부여한다.
