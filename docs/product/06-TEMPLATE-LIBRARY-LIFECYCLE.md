# 템플릿 라이브러리 관리 기준

## 상태와 표준

- 상태는 `초안(draft)`, `검토 완료(ready)`, `게시됨(published)`, `보관됨(archived)`을 사용한다.
- `표준(isStandard)`은 상태가 아니라 새 템플릿 제작의 기준으로 사용할지 나타내는 독립 값이다.
- 하나의 템플릿이 `게시됨 + 표준` 또는 `검토 완료 + 표준`일 수 있다.
- 라이브러리의 상태·표준 필터에 같은 템플릿이 나타나더라도 원본 ID는 하나다.

## 디자인 보호

- 표준이 아닌 템플릿은 초안, 검토 완료, 게시됨, 보관됨 상태와 관계없이 현재 원본을 직접 편집할 수 있다.
- 표준 템플릿만 디자인 편집을 허용하지 않는다.
- 보호된 템플릿을 바탕으로 변경하려면 `이 템플릿으로 새로 만들기`를 사용한다.
- 새 템플릿은 새 ID, 초안 상태, 표준 해제로 시작하므로 원본과 사용자 서비스 게시본에 영향을 주지 않는다.

## 라이브러리 카드 기능

- `이 템플릿으로 새로 만들기`: 템플릿 설정을 먼저 열고 새 ID의 초안을 만든다.
- `편집`: 표준이 아닌 템플릿의 디자인을 같은 ID의 다음 버전으로 저장한다.
- `설정`: 디자인을 바꾸지 않고 이름, 설명, Edition, 상태, 표준 여부를 저장한다.
- 과거의 `연결 작업본 만들기`, 카드 `복제`, 순환식 `상태 변경`은 사용하지 않는다.

## 사용자 서비스 노출

- 사용자 서비스 선택 목록에는 `published` 상태만 노출한다.
- `isStandard`는 사용자 서비스 노출 조건이 아니다.
- 상태를 게시됨으로 저장하기 전까지 기존 게시 템플릿에는 새 초안의 변경이 반영되지 않는다.
- 게시·표준 템플릿의 교체는 새 초안 제작, 검토 완료, 게시, 필요 시 기존 템플릿 보관 순서로 명시적으로 진행한다.

## 추후 인쇄·출력 품질 검사

- 카드에는 `인쇄·출력 품질 검사 · 준비 중` 버튼을 유지하되 현재는 실행하지 않는다.
- 기존 Package 구조 검사와 혼동하지 않도록 Package 검사 명칭과 실행 동작은 제거한다.
- 추후 검사 범위는 재단·도련·안전선, 페이지 수와 순서, 출력 규격, 이미지 해상도, 누락 Binding, PDF/X-4 변환 및 Preflight 결과로 정의한다.
- 과거 버전은 이력과 복원만 제공하며 별도의 버전 미리보기는 제공하지 않는다.
