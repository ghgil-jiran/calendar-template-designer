# Product Vision

## 문제

학교는 매년 학사달력, 학교신문, 문집, 보고서 등 다양한 출판물을 제작합니다. 그러나 학교 고유 정보와 일정 데이터를 반복 입력하고, 디자인 파일과 실제 사용자 데이터가 분리되며, 최종 인쇄 품질을 별도로 확인해야 하는 문제가 있습니다.

## 비전

**Canvas Publishing Platform**은 학교 출판물의 구조를 이해하는 도메인 기반 편집·출판 플랫폼입니다.

첫 번째 제품인 **Academic Calendar Designer**는 다음 두 사용자를 연결합니다.

- 디자이너: 재사용 가능한 학사달력 템플릿 제작
- 학교 사용자: 학교 정보와 학사일정을 적용해 최종 달력 제작

## 제품 원칙

### Domain First

범용 그래픽 편집기보다 `표지`, `간지`, `월력`, `뒷표지`, `학교 일정`처럼 사용자가 실제로 이해하는 학사달력 개념을 중심으로 설계합니다.

### One Contract, Multiple Outputs

동일한 Template Contract와 Dataset Contract가 편집 미리보기, 사용자 Workspace, 화면 출력, 인쇄 출력의 기준이 됩니다.

### Release Before Perfection

기능을 끝없이 추가하기보다, 검증된 상태를 버전으로 공유하고 동료와 사용자 피드백을 다음 개발 사이클에 반영합니다.

## 장기 방향

학사달력을 시작으로 학교문집, 학교신문, 보고서 표지 등 학교 출판물로 확장할 수 있는 공통 Runtime과 편집 기반을 구축합니다. 다만 현재 제품 범위는 학사달력에 집중합니다.
