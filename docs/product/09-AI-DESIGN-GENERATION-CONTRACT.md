# AI 디자인 생성 계약 초안

- 문서 버전: 0.2.0
- 적용 모듈: AI 디자인 에디터 v1.1
- 상태: 모의 시안 검증용

## 1. 목적

실제 AI 모델을 연결하기 전에 `템플릿 설정 → ⑨ AI 디자인 생성`이 주고받을 데이터 단위를 고정한다. 생성 결과는 완성 페이지 이미지 한 장이 아니라 디자인 세트와 페이지 역할별 결과로 관리한다.

## 2. 시작 템플릿 참고 계약

AI 연동 전후 모두 현재 선택한 시작 템플릿의 실제 대표 페이지를 참고 입력으로 사용한다. 대표 역할은 표지·연력·월력·월력 뒷면·뒷표지이며, 사용자는 전체 디자인 언어·색상·배치·장식 요소·사진 표현 중 참고할 항목을 선택한다.

생성 요청의 `referenceTemplate`에는 템플릿 ID·이름·버전, 역할별 페이지 ID, 선택한 참고 항목과 `readOnly: true`를 기록한다. 이 참조는 렌더링과 분석 입력으로만 사용하며 시작 템플릿이나 Published Package를 수정하지 않는다.

## 3. 생성 세션

생성 세션은 생성 범위, 학교급, 장식 밀도, 사진 사용 방식, 계절 변화, 추가 지시와 독립 규칙 버전을 기록한다. 생성 범위는 선택 영역, 현재 페이지, 같은 역할의 페이지, 월별 페이지 전체, 템플릿 전체 디자인 세트를 지원한다.

## 4. 디자인 세트 시안

각 시안은 다음을 포함한다.

- 공통 색상과 조형 언어
- 독립 이미지 자산 목록
- 기존 편집 개체에 적용할 스타일
- 전체 배치 방향
- 페이지 역할별 생성 계획
- 가독성·안전 영역·인쇄 위험 검사 결과

## 5. 페이지 역할별 결과

초기 대표 역할은 표지, 연력, 월력, 월력 뒷면, 뒷표지다. 각 역할은 다음 단위로 반환한다.

- 배경·패턴·일러스트·프레임 등의 독립 이미지 자산
- 연도·학교명·월·요일·날짜·일정 등 기존 편집 개체 참조
- 개체별 스타일 제안
- 위치·크기·정렬·겹침 순서 배치안
- 사용자 지정 개체 또는 복합 개체 후보
- 생성 버전과 품질 검사 결과

연도, 학교명, 날짜, 학사일정, 주소와 연락처는 이미지 안에 생성하지 않는다.

## 6. 응답 분리 단위

정식 응답 `ai-design-generation-response.v1`은 최소한 `assets`, `objectStyles`, `layouts`, `pageResults`, `qualityChecks`를 서로 분리해 반환한다. 고화질 RGB 원본 자산은 보존하고, 기존 데이터 개체는 이미지 속 글자로 생성하지 않는다.

현재 구현된 `ai-design-generation-request.v1`은 실제 모델이나 외부 API를 호출하지 않는다. ⑨단계에서 실제 대표 페이지와 조건을 조립해 요청 경계를 검증하며, 다음 단계의 실제 샘플 생성기가 이 계약을 사용한다.

### 2026-09-05 실제 생성 자산 검증

API 상시 연결 전에 동일 금지 조건으로 실제 AI 생성 자산 4종을 만들었다. 자산은 RGB PNG 원본과 `sample-assets/manifest.json`으로 버전을 고정하며, 편집 가능한 텍스트·달력 개체 모형을 별도 레이어로 합성해 시안을 확인한다. 선택 자산은 복제된 새 템플릿 초안에 `ai-design-background` 개체로 적용되며 원본과 Published Package는 그대로 유지한다.

## 7. 부분 재생성

디자인 세트를 유지하면서 선택한 페이지 역할 또는 선택한 요소만 새 결과로 교체한다. 재생성 이력과 사용한 규칙 버전을 남기며 다른 페이지와 원본 템플릿은 변경하지 않는다.

## 8. 초안 경계

시안 선택만으로 템플릿에 디자인을 적용하지 않는다. 선택 결과는 `selected-not-applied` 상태의 별도 AI 디자인 초안으로 저장한다. 이후 적용·저장·재열기·Runtime·PDF 검증을 통과한 결과만 재사용 가능한 디자인 세트 후보가 된다.
