# Project Charter

## Project 1 — Calendar Template Designer v1.0 Beta

학교용 학사달력의 구조와 템플릿 규칙을 정의하고 디자이너가 다양한 달력 템플릿을 제작·검증·배포할 수 있는 기준 시스템을 완성한다.

### 포함

- Designer Studio
- CalendarType
- Template / Master / Page / Object / Binding
- Asset 관리
- Preview Workspace
- Template JSON 내보내기
- 문서화, GitHub, 독립 배포

### 제외

- 사용자용 Workspace 신규 개발
- PDF 엔진 신규 개발
- 공휴일·음력·절기 기관 연동 신규 개발
- 멀티테넌트 SaaS
- AI 템플릿 생성
