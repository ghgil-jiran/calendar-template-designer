# AI 디자인 에디터 v1.1 기능 구조 기획안

- 상위 제품: `달력 템플릿 에디터 v1.3`
- 독립 모듈: `AI 디자인 에디터 v1.1`
- 문서 버전: `0.1.0`
- 상태: 기능 구조 검토안
- 기준 문서: `07-AI-DESIGN-EDITOR-ROADMAP.md`

## 1. 목표

달력 템플릿 에디터 안에서 AI가 이미 확정된 상품·페이지 구조에 맞는 디자인 요소와 배치안을 생성하고, 디자이너가 이를 비교·선택·부분 재생성·적용·편집·저장해 실제 템플릿으로 완성한다.

샘플 수집이나 분석 자체를 제품 기능으로 만들지 않는다. 샘플은 프롬프트와 스타일 규칙의 품질을 개선하는 참고자료다.

## 2. 모듈 경계

기존 템플릿 에디터는 상품 규격, 페이지·Master 구조, 달력 데이터, 편집 개체, Canvas, Inspector, 저장, Runtime과 출력을 계속 소유한다. AI 디자인 에디터는 그 구조를 교체하지 않고 다음 결과를 생성·제안한다.

1. 배경·패턴·일러스트·장식·사진 프레임 등의 독립 이미지 자산
2. 기존 텍스트·벡터·달력 개체에 적용할 스타일
3. 개체의 위치·크기·정렬·겹침 순서를 정하는 배치안
4. 기존에 없는 사용자 지정 개체 또는 복합 개체 후보

연도, 학교명, 월·요일·날짜, 공휴일, 학사일정, 연력, 미니월력, 띠 월력, 플래너와 연락처는 이미지에 고정하지 않고 기존 데이터 연결 개체로 유지한다.

## 3. 정식 진입과 사용자 흐름

AI 디자인 생성은 편집 화면의 상시 도구가 아니라 새 템플릿 제작 설정의 한 단계다.

1. `새 템플릿 만들기`
2. 상품 규격과 페이지 구성 선택
3. `템플릿 설정` 단계별 작성
   - 기본 설정
   - 학교 정보 및 에셋
   - 색상 테마
   - 폰트 테마
   - Master 관리
   - 일정 분류
   - 출력 설정
   - 그래픽 라이브러리
4. `AI 디자인 생성`
5. 생성 범위와 디자인 조건 선택
6. 디자인 시안 2~4개 생성
7. 전체·페이지별·요소별 비교와 부분 재생성
8. 선택 결과의 적용 전후 비교
9. 원본과 분리된 `AI 디자인 적용 초안` 생성
10. 기존 편집 화면에서 위치·크기·색상·투명도·겹침 순서 조정
11. 검증된 결과를 재사용 가능한 디자인 세트로 저장
12. 검증된 스타일×구성 조합만 사용자 서비스에 제공

## 4. 생성 범위

- 선택 영역
- 현재 페이지
- 같은 역할의 페이지
- 월별 페이지 전체
- 템플릿 전체 디자인 세트

전체 디자인 세트는 표지·연력·간지·월력·월력 뒷면·뒷표지에 같은 색상과 조형 언어를 유지하면서 월별 계절 변화와 페이지 역할의 차이를 표현한다.

## 5. 템플릿 설정에서 전달할 입력

- 상품 유형, 제작·재단 크기, 도련과 안전 영역
- 페이지 순서, 페이지 역할과 Master
- 학교급, 학교 분위기, 학교 정보와 보호할 사진·교표
- 색상·폰트 방향과 변경 허용 범위
- 월력 프리셋과 필요한 정보 밀도
- 사진 사용 방식과 기존 그래픽 자산
- 장식 밀도, 화려함의 상한과 금지 조건
- 최소 글자·선, 유효 해상도와 인쇄 색상 조건

## 6. 시안과 부분 재생성

시안은 단일 미리보기 이미지가 아니라 독립 자산, 기존 개체 스타일, 배치안과 사용자 지정 개체 후보의 묶음이다. 다음 단위로 다시 생성할 수 있어야 한다.

- 전체 디자인 세트
- 특정 페이지 역할
- 특정 페이지
- 특정 자산 또는 장식
- 자산은 유지하고 배치만 변경
- 배치는 유지하고 색상·스타일만 변경
- 다른 시안의 선택 요소로 교체

부분 교체 뒤에도 전체 스타일 규칙과 인쇄 안전 기준을 다시 검사한다.

## 7. 적용·비교·되돌리기

- 시안 선택만으로 원본 템플릿을 변경하지 않는다.
- 적용 전 원본, 선택 시안과 현재 수정본을 비교한다.
- AI 디자인 전체 적용은 하나의 변경 묶음으로 되돌릴 수 있어야 한다.
- 초안 생성 이후의 개별 수정은 기존 Undo/Redo와 편집 이력을 사용한다.
- 원본 템플릿 ID·버전과 파생된 AI 디자인 초안의 관계를 보존한다.

## 8. 저장 단위

### 생성 세션

선택 전 시안, 생성 범위, 디자인 조건과 사용한 규칙 버전을 임시 보관한다.

### AI 디자인 적용 초안

선택한 결과를 원본과 분리된 새 템플릿 초안으로 저장한다. 기존 Published Package나 검토 템플릿을 덮어쓰지 않는다.

### 디자인 세트

검증된 스타일 규칙, 페이지 역할별 자산, 배치안, 기존 개체 스타일, 월별 변화 규칙, 호환 상품·구성 타입과 검증 결과를 묶어 저장한다.

## 9. 독립 버전 계약

다음 항목은 템플릿 에디터 본체와 분리해 각각 버전을 가진다.

- `aiDesignModuleVersion`
- `promptSetId`와 `promptSetVersion`
- `styleProfileId`와 `styleProfileVersion`
- `pageRuleSetId`와 `pageRuleSetVersion`
- `qualityProfileId`와 `qualityProfileVersion`

모든 생성 세션·시안·AI 디자인 초안·디자인 세트는 사용한 버전을 기록한다. 새 버전은 이전 결과와 Published Package에 자동 적용하지 않는다.

버전 변경 원칙:

- major: 저장 계약이나 생성 결과 해석 방식의 호환이 깨지는 변경
- minor: 새 생성 범위, 새 자산 유형, 새 페이지 규칙 또는 평가 항목 추가
- patch: 기존 의미를 바꾸지 않는 프롬프트 조정, 설명·금지 조건·평가 기준 보완

프롬프트만 수정할 때 템플릿 에디터 본체를 새로 배포하지 않아도 되도록 규칙 저장과 로딩 경계를 분리한다. 다만 사용 가능한 규칙 버전과 호환 모듈 버전은 명시적으로 검증한다.

## 10. 사용자 지정 개체 승격

새로운 띠 월력, `Yearly Check List`, 복합 메모 블록과 같은 표현은 먼저 해당 AI 디자인 초안 내부의 사용자 지정 항목으로 저장한다.

1. 데이터 연결과 편집 가능 범위 확인
2. 저장·재열기 확인
3. Runtime·미리보기·PDF 결과 확인
4. 관리자 검토와 명칭·범위 확정
5. 공통 기본 옵션 또는 정식 복합 개체로 승격

## 11. 사용자 서비스 제공

사용자 서비스에는 검증된 디자인 스타일 3~4종과 구성 타입 4~5종을 독립 축으로 제공한다. 사용자에게는 검증된 조합만 완성 템플릿으로 표시한다. 내부에는 각 스타일·구성·디자인 세트와 Template Package의 정확한 버전을 보존한다.

## 12. 인쇄 품질 연결

- 생성 전: 실제 페이지 비율, 도련·안전 영역, 보호 영역과 필요한 해상도 전달
- 시안 비교: 장식 과밀, 정보 가독성, 색역, 유효 해상도, 얇은 선·작은 글자 검사
- 편집 완료 전: RGB 원본 보존, 벡터 개체 유지와 CMYK 예상 결과 비교
- 최종 출력: 지정 ICC 변환, PDF/X-4 생성, Trim/Bleed·폰트·투명 효과와 Preflight

## 13. 현재 구조의 판정

### 유지

- Template·Dataset·ResolvedDocument 경계
- 페이지 역할, Master와 페이지별 개체 구조
- Canvas, Inspector, Undo/Redo와 버전 이력
- `acdl-asset://` 자산 저장과 Runtime·미리보기·PDF 공통 결과 원칙
- 월력 프리셋과 날짜 계산

### 보강

- 템플릿 설정의 단계별 입력과 AI 생성 입력 연결
- 기존 적용 범위를 선택 영역·같은 역할·월별 전체·전체 세트로 확장
- 자산과 개체에 생성 출처·역할·규칙 버전 기록
- Undo/Redo에 AI 일괄 적용 변경 묶음 추가
- 템플릿 복제로 AI 디자인 적용 초안 생성
- 미리보기에 시안과 적용 전후 비교 추가

### 신규

- 템플릿 설정의 `AI 디자인 생성` 단계
- 생성 세션과 시안 관리 계약
- 독립 프롬프트·스타일·페이지 규칙·평가 기준 저장소
- 디자인 세트 계약
- 부분 재생성·요소 교체
- 사용자 지정 복합 개체 검증 상태
- 생성 단계 인쇄 적합성 검사
- 검증된 스타일×구성 조합 목록

## 14. 첫 구현 묶음

실제 AI 모델을 연결하기 전에 다음 흐름을 가짜 시안 데이터로 검증한다.

1. 템플릿 설정에 `AI 디자인 생성` 단계를 표시한다.
2. 앞 단계 설정에서 생성 입력 요약을 만든다.
3. 생성 범위와 디자인 조건을 선택한다.
4. 고정된 가짜 시안 2~4개를 비교한다.
5. 페이지·요소 단위 선택과 부분 교체를 시험한다.
6. 적용 전후 비교와 전체 적용 되돌리기를 확인한다.
7. 원본과 분리된 AI 디자인 적용 초안을 저장한다.
8. 저장·재열기와 기존 Runtime·미리보기·PDF가 영향을 받지 않는지 검사한다.

이 묶음이 통과한 뒤 단일 이미지 자산 생성부터 실제 AI 연결을 시작한다.
