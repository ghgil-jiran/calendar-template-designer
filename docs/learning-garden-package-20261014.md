# 배움의 정원 · 학교 이야기

- 사용자 선택 시안 1의 세부 보존 SVG를 원본으로 사용한다. 형태를 유지하는 SVGO 최적화로 약 10MB를 1.5MB로 줄였다.
- 공통 그래픽 라이브러리에는 `배움의 정원 · 학생과 책`을 독립 SVG 자산으로 제공한다. 주제는 책·독서이다.
- 별도의 `배움의 정원 · 표지` SVG를 만들어 `배움의 정원 · 학교 이야기` 패키지의 표지에 연결한다. 표지 배경은 전체 자산 목록에서 제외되고 패키지에서 관리한다.
- 규격은 탁상 표준형 260×180mm. 왼쪽 일러스트, 오른쪽 학교 사진 타원 영역, 상단 연도·CALENDAR, 하단 교표·학교명·주소·연락처를 예약한다. 사진과 문구는 SVG에 넣지 않으며 편집 화면의 별도 개체로 배치한다.
- 패키지 표지에서 등록된 실제 SVG를 표시하고 배경/배치 예시를 전환한다. 임시 생성 배경으로 바꾸지 않는다. 다른 페이지 선택은 기존 생성 흐름과 연결되며, 후속 디자인은 별도로 검수해야 한다.
- 인증된 라이브러리의 기본 자산 확인 과정에서 등록한다. 등록 마커와 안정된 ID로 재등록을 막고, 중단된 등록을 재개하며 편집·보관·삭제한 자산을 보존한다.
- 안전한 SVG 구조 검사는 유지하고 허용 크기를 4MB로 통일했다. 스크립트·텍스트·외부 참조·포함 래스터는 사용하지 않는다.
- 원본/표지 SVG 렌더링 확인, 등록·재개·삭제 보존·패키지 표지 재열기와 다른 페이지 이동 테스트 통과. 최종 CMYK PDF와 실인쇄는 별도 검증 대상이다.
