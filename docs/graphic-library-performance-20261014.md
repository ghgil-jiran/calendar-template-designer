# 공통 그래픽 라이브러리 조회 개선

- Storage 파일 목록의 수정 시각과 메타데이터로 자산 정보 JSON의 변경을 확인한다.
- 별도 private 목록 인덱스는 재생성 가능한 사본이며, 파일 목록에 없는 자산은 표시하지 않는다. 인덱스가 없거나 손상되면 원본 JSON 조회로 복구한다. 인덱스 저장 실패도 목록 표시를 막지 않는다.
- 기본 자산 등록 확인은 `install=1` 명시 요청으로 분리하고 첫 목록 표시 뒤 세션당 한 번 실행한다. 기존 등록·보관·삭제 보호 정책은 유지한다.
- 목록 응답에서 벡터 좌표를 제외한다. 상세 보기와 벡터 추가 시 전체 자산 정보로 복원한다. 패키지 편집용 디자인과 생성 이력은 유지한다.
- 다시 열 때 현재 목록을 바로 표시하고 서버 조회 결과로 갱신한다. 썸네일 보완은 완료를 기다리지 않으며, 보이는 카드 주변부터 최대 4개씩 처리한다. 원본 자산은 변경하지 않는다.
- 120개 자산 테스트: 첫 인덱스 생성 시 정보 JSON 120회, 변경 없는 재조회 0회, 하나 수정 시 1회 조회. 삭제와 보관 반영 및 손상된 인덱스 복구 검증.
- 전체 build·패키지·Studio 869개·제품 상호작용 검사 통과. 실제 로그인 환경의 시간 단축은 별도 확인 필요.
