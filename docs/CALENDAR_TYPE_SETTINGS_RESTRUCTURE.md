# 달력 유형 및 새 템플릿 설정 구조

## 소유권

달력 유형은 실제 제작 가능한 제품의 규격과 구조적 허용 범위만 소유한다. 디자인 스타일, 월력 격자, 미니월력·공휴일·음력·절기 표시값, 학교 정보와 자산, AI 조건, 일반 개체 목록, 실제 페이지 수는 템플릿 설정이 소유한다.

| 값 | 달력 유형 | 템플릿 설정 |
|---|---|---|
| 제품군·규격·방향·제본·단/양면 | 정의 | 읽기 전용 확인 |
| 표지·뒷표지·월력 앞/뒤·연간 한 면 | required/optional/unsupported | optional만 사용 여부 선택 |
| 간지·개월 수·시작 월 | 최소·최대 또는 허용값 | 범위 안 실제 값 선택 |
| 페이지 역할 | 필수·선택·반복 규칙 | 실제 페이지 구성 |
| 디자인·달력 표시·학교 정보·Master·AI | 소유하지 않음 | 실제 값 선택 |

## 초기 유형

- 탁상달력: 스탠다드, 라지, 세로형, 와이드형
- 한 장 달력: 포스터형
- 벽걸이형: 스탠다드 299×419mm, 라지 388×544mm, 라지 플러스 501×700mm
- 제외: 엽서형, A4 벽걸이형, 기존 테스트 벽걸이형

기존 템플릿은 저장 데이터 분석 없이 모두 `desk-standard`로 호환한다. `wall`로 저장된 기존 테스트 템플릿에는 새 벽걸이 유형을 자동 배정하지 않는다.

## 저장과 스냅샷

시스템 공통 유형은 Supabase 5개 테이블에 저장하고 `/api/calendar-types`를 통해서만 접근한다. 새 템플릿은 `template.calendarTypeSnapshot`에 생성 당시 정의 전체를 저장한다. 이후 공통 유형이 바뀌어도 기존 템플릿의 크기와 페이지를 자동 변경하지 않는다.

## 생성 방식

새 템플릿은 선택한 유형의 빈 구성에서 시작하고 AI 디자인도 새로 생성한다. 기존 템플릿 기반 제작은 템플릿 라이브러리의 기존 복제 흐름만 사용한다. 달력 유형·제작 규격을 별도 단계로 반복하지 않고 기본 설정 상단에서 읽기 전용 유형 요약과 허용 제약으로 표시한다.
