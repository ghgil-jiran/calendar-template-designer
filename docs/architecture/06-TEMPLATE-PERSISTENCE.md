# 템플릿 영구 저장과 버전 기록

## 확정한 사용자 경험

- 템플릿 라이브러리에는 템플릿별 최신본 한 개만 표시한다.
- `저장`은 같은 템플릿에 수정 불가능한 새 버전을 추가한다.
- `다른 이름으로 저장`은 별도의 새 템플릿을 만든다.
- 자동저장은 버전을 계속 만들지 않고 템플릿별 임시 작업본 한 개만 갱신한다.
- 이전 버전은 별도의 버전 기록에서만 보고, 복원하면 과거 기록을 수정하지 않고 새 최신 버전을 만든다.
- 배포본 지정도 새 버전으로 기록해 어떤 내용이 사용자 서비스에 전달됐는지 남긴다.

## 저장 영역

| 저장 영역 | 역할 | 화면 노출 |
|---|---|---|
| `template_projects` | 이름, 상태, 최신 버전 번호와 라이브러리 카드 | 기본 라이브러리 |
| `template_versions` | 명시적 저장·복원·배포 이력과 전체 프로젝트 JSON | 버전 기록 |
| `template_drafts` | 자동저장 임시 작업본 한 개 | 복구 안내가 필요할 때만 |
| `template_assets` | 해시가 같은 이미지를 한 번만 보관 | 자산 선택·미리보기 |
| `template_version_assets` | 특정 버전이 사용한 이미지 목록 | 내부 무결성 검사 |

## 저장 규칙

1. 새 템플릿을 처음 저장하면 `template_projects` 한 건과 버전 1을 만든다.
2. 같은 템플릿을 저장하면 라이브러리 행은 갱신하고 `template_versions`에 다음 번호를 추가한다.
3. 정식 저장이 성공하면 해당 템플릿의 자동저장 임시본을 제거한다.
4. 이전 버전 복원은 `save_kind=restore`, `source_version_id=과거 버전 ID`인 새 버전으로 남긴다.
5. 과거 버전은 수정·삭제하지 않는다.
6. 라이브러리 조회는 `archived_at is null`인 `template_projects`만 읽고 버전 행을 직접 나열하지 않는다.

## 이미지 규칙

- 이미지는 비공개 `template-assets` 버킷에 저장한다.
- 프로젝트 JSON에는 Base64 원본 대신 자산 ID와 경로를 기록한다.
- SHA-256 내용 해시가 같으면 기존 자산을 재사용한다.
- 허용 형식은 PNG, JPEG, WebP, SVG이며 파일당 상한은 20MB다.
- 브라우저에는 Supabase 서비스 키나 비공개 원본 경로를 노출하지 않는다.

## 연결 경계

- 현재 IndexedDB 저장은 오프라인 작업과 전환 중 안전장치로 유지한다.
- Vercel 배포본은 브라우저에서 Supabase를 직접 호출하지 않고 `/api/templates` 계열 서버 경로를 사용한다.
- 서버만 Supabase 서비스 키를 사용한다.
- 첫 단계는 본인 한 명이 사용하는 개발·검토용 저장소이며, 다중 사용자 권한과 공동 편집은 이후 범위다.
