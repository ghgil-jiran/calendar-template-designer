# Project Handoff

## 현재 상태

Project 1은 학사달력 템플릿 구조와 Designer Studio를 마감하고 GitHub에 배포하기 위한 단계다.

2026-09-02 기준 다음 최우선 작업은 [`월력 디자인 프리셋 시스템`](../architecture/MONTHLY-CALENDAR-PRESET-SYSTEM.md)이다. 월력을 고정 표로 보정하는 작업을 중단하고 날짜 계산과 표현 프리셋을 분리한다.

현재 Production은 잘못된 SVG 격자 레이어를 제거한 안정 상태다. 코드 기준은 `51665c2`, 회귀검사 기준은 `e59321d`다.

## 다음 채팅에서 바로 시작할 작업

1. 새 월력 프리셋 계약을 `packages/contracts`와 Runtime 경계에 맞춰 확정한다.
2. 샘플 3번·6번 PDF에서 월 제목·요일·날짜 영역·선·일정·미니 월력 치수를 측정한다.
3. 샘플 6 계열 박스형을 첫 프리셋으로 구현한다.
4. 5행·6행, 일정 과밀, 미니 월력, 12개월, 화면 크기, PDF 회귀검사를 통과시킨다.
5. 샘플 3 계열 끊어진 가로선형을 독립 프리셋으로 구현한다.

내부 요소 자유 배치는 초기 범위가 아니며 장기 후속 작업이다. 초기 목표는 완성도 높은 프리셋 5~6종과 디자이너용 선택·제한 조정 기능이다.

## 최근 마감 대상

- 달력 유형 관리 닫기 → Designer Studio 복귀
- CalendarType별 복수 크기 프리셋
- `디자인 시작점` → `시작 템플릿`
- Postcard / Wall 편집 점검
- 월별 이미지 업로드와 메모리 모니터 점검
- 릴리스 문서와 Known Issues 정리

## 변경하면 안 되는 원칙

- Preview Workspace는 최종 사용자 제품이 아니다.
- 사용자 Workspace를 다시 만들지 않는다.
- 외부 MVP의 UI/UX, PDF, 데이터 연동 강점을 활용한다.
- 학사달력의 Template / CalendarType / Binding 설계는 이 프로젝트가 중심이다.
- 통합은 화면 결합보다 Contract 확정이 먼저다.
- 5×7·6×7은 날짜 배치 구조이며 월력 디자인 자체가 아니다.
- 샘플 3번·6번을 한 표의 선 표시 옵션으로 합치지 않는다.
- 월력 셀별 예외 CSS 또는 실제 셀과 분리된 거대 SVG 격자로 문제를 덮지 않는다.
- 모든 초기 월력 프리셋은 5행·6행을 모두 지원한다.
