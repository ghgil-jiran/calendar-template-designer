# 우리학교인쇄 서비스 경계

## 목적

Calendar Template Designer와 Template Runtime은 우리학교인쇄 안에서 호출되는 편집·출판 엔진이다. 우리학교인쇄의 회원, 주문, 결제, 배송 기능을 대체하지 않는다.

## 책임 분리

### Calendar Publishing Platform
- 템플릿 제작과 관리
- 사용자 편집 데이터 해석
- 미리보기와 레이아웃 계산
- 인쇄 규칙 검증
- 최종 인쇄용 파일 및 메타데이터 생성

### 사용자용 Academic Calendar Workspace MVP
- 템플릿 선택과 사용자 입력
- 학교 정보와 일정 편집
- 금액 산정 화면
- 주문 전 편집 흐름

### 우리학교인쇄
- 사용자와 학교 식별
- 상품, 견적, 주문, 결제
- 제작 상태와 배송
- 최종 인쇄 파일 수신 및 인쇄소 전달

## 통합 원칙

1. 현재 엔진을 독립 환경에서 먼저 검증한다.
2. 사용자 MVP를 Runtime Contract에 연결한다.
3. 파일·가격·주문 데이터 계약을 검증한다.
4. 통합 QA가 끝난 뒤 우리학교인쇄 운영 서버에 배포한다.
5. 운영 서버 구조에 맞추기 위해 제품 기능을 축소하거나 레거시 필드를 그대로 복제하지 않는다.
