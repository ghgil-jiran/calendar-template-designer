# Sprint 2 Editor Core 테스트 가이드

## 자동 테스트

```bash
npm install
npm run test:sprint2
npm run verify
```

## 브라우저 데모

```bash
npm run demo:sprint2
```

브라우저에서 `http://localhost:4172`를 엽니다.

## 수동 테스트 체크리스트

1. 개체를 클릭하면 파란 선택 테두리가 표시된다.
2. Shift+클릭하면 여러 개체를 함께 선택할 수 있다.
3. 선택한 개체를 드래그하면 이동한다.
4. 다중 선택 상태에서 드래그하면 선택한 개체들이 함께 이동한다.
5. 이동 중 10px 그리드, 다른 개체의 가장자리/중앙, 캔버스 중앙에 스냅된다.
6. 오른쪽 아래 핸들로 크기를 조절할 수 있다.
7. 위쪽 원형 핸들로 회전할 수 있다.
8. 맨 앞으로/맨 뒤로 버튼으로 레이어 순서가 변경된다.
9. 잠긴 개체는 이동·크기 조절·회전·삭제되지 않는다.
10. 숨긴 개체는 흐리게 표시되며 다시 표시할 수 있다.
11. Delete 키 또는 삭제 버튼으로 선택 개체를 삭제할 수 있다.
12. 실행 취소/다시 실행 버튼 및 Ctrl+Z/Ctrl+Y가 동작한다.
13. 초기화 버튼으로 최초 상태로 돌아간다.

## Sprint 2 통과 기준

- `npm run verify`가 오류 없이 완료된다.
- 위 체크리스트 13개 중 치명적 오류가 없다.
- 테스트 중 발견한 문제는 다음 Sprint 전에 수정 목록으로 기록한다.
