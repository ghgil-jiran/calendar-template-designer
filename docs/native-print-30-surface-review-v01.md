# 30면 네이티브 인쇄 기준본 1차 검토

## 검토 기준

- 물리적 페이지 역할과 페이지에 들어간 콘텐츠 유형을 분리한다.
- 이번 검토는 30면의 구조·순서·바인딩·네이티브 인쇄 구조를 확인하는 0.9 기준본 검토다.
- 현재 CMYK 이미지는 실제 학교 자산이 아닌 승인된 검사용 픽스처다.
- 현재 30면 기준본에는 뒤 간지가 없다. 뒤 간지를 선택한 템플릿은 `rear-insert-front`, `rear-insert-back`을 월력과 뒷표지 사이에 추가한다.

## 전체 면 구성

| 면 | 물리적 페이지 | 내부 role | 현재 콘텐츠 |
|---:|---|---|---|
| 1 | 표지 | `cover-front` | 표지 디자인 |
| 2 | 표지 안쪽면 | `cover-back` | 연력 |
| 3 | 앞 간지 앞면 | `front-insert-front` | 학교 상징 |
| 4 | 앞 간지 뒷면 | `front-insert-back` | 학사 일정 |
| 5~28 | 월력 앞면·뒷면 12쌍 | `monthly-front`, `monthly-back` | 2028년 3월~2029년 2월 |
| 29 | 뒷표지 안쪽면 | `back-cover-front` | Yearly Plan |
| 30 | 뒷표지 | `back-cover-back` | 학교 정보 뒷표지 |

## 페이지군별 1차 판정

### 1. 표지·표지 안쪽면

- 구조: 통과. 표지와 표지 안쪽면이 서로 다른 물리적 role로 유지된다.
- 바인딩: 표지 연도·학교명·슬로건, 연력의 3월 시작 12개월이 정상이다.
- 0.9 유형 지원: 표지는 중앙 사진형·왼쪽 사진형·오른쪽 사진형·자유 구성형을 네이티브 편집 개체로 생성한다. 자유 구성형은 대표 사진을 필수로 생성하지 않는다.
- 0.9 유형 지원: 연력은 무박스 그리드형·월별 개별 박스형·세로 3개월 그룹형·가로 4개월 그룹형을 선택값과 레이아웃 메타데이터로 유지한다. 연도와 12개월 월력은 필수이고 교표는 선택이다.
- 후속: 실제 학교 이미지·교표를 적용하고 표지 유형별 필수·선택 개체를 검증한다.
- 정밀화 후속: 연력의 무박스·그룹 구분선이 실제 인쇄 PDF에서 선택 유형별로 더 명확하게 달라지도록 전용 스타일 표현을 보강한다.

### 2. 앞 간지 앞면·뒷면

- 구조: 통과. 학교 상징과 학사 일정은 간지의 콘텐츠이며 물리적 role을 대체하지 않는다.
- 바인딩: 교훈·교목·교화·교가와 연간 학사 일정이 Runtime에 전달된다.
- 후속: 학교 소개·사용자 정의 등 다른 간지 용도에도 동일한 네이티브 개체 규칙을 적용해야 한다.

### 3. 월력 앞면·뒷면 12쌍

- 구조: 통과. 3월부터 다음 해 2월까지 12쌍이 순서대로 생성된다.
- 바인딩: 연도·월·날짜·미니 월력·해당 월 학사 일정·월 띠력이 페이지별로 정상이다.
- 후속: 월력 앞면의 공휴일·학사일정 표현, 뒷면 4가지 레이아웃 유형, 월별 이미지 교체를 실제 템플릿에서 검증해야 한다.

### 4. 뒷표지 안쪽면·뒷표지

- 구조: 통과. Yearly Plan은 `back-cover-front`에 들어간 콘텐츠이고, 마지막 면은 `back-cover-back`이다.
- 바인딩: Yearly Plan 12개월과 뒷표지의 연도·교표·학교명·주소·연락처가 정상이다.
- 후속: 뒷표지 3가지 유형과 실제 학교 자산을 적용한 편집·인쇄 동일성을 검증해야 한다.
