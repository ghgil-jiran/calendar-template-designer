# Sprint 2 실제 Designer Studio 통합 테스트

## 실행

```bash
npm install
npm run verify
npm run dev
```

브라우저에서 `http://localhost:4173`을 연다.

## 테스트 준비

1. 시작 화면에서 `새 템플릿 만들기`를 선택한다.
2. 탁상형과 기본 템플릿을 선택해 템플릿을 생성한다.
3. 표지 또는 월력 페이지에서 텍스트, 이미지, 도형 중 두 개 이상을 추가한다.

## Canvas 테스트

- 개체 클릭: 선택 테두리와 상단 선택 도구막대가 표시된다.
- Shift+클릭: 여러 개체가 동시에 선택된다.
- 드래그: 선택 개체가 이동한다. 다중 선택 상태에서는 함께 이동한다.
- 8개 크기 조절점: 상하좌우와 모서리 방향으로 크기를 변경한다.
- 원형 회전점: 개체를 회전한다. 기본 5도 단위이며 Shift를 누르면 자유 회전한다.
- 방향키: 선택 개체를 미세 이동한다. Shift+방향키는 더 크게 이동한다.
- 맨 앞으로/맨 뒤로: 선택 도구막대에서 레이어 순서를 바꾼다.
- 복제: 선택 개체를 복사한다.
- 잠금: 잠근 개체는 Canvas에서 움직이지 않는다.
- 숨김: 선택 개체를 Canvas에서 숨긴다.
- Delete: 선택 개체를 삭제한다.
- Ctrl+A: 현재 페이지의 모든 개체를 선택한다.
- Ctrl+Z / 다시 실행: 기존 상단 실행 취소/다시 실행과 함께 변경 이력을 확인한다.

## 통과 기준

각 조작 후 오른쪽 Inspector와 Canvas 결과가 같은 위치·크기·회전 값을 나타내고, 저장 후 JSON을 다시 불러왔을 때 결과가 유지되어야 한다.
