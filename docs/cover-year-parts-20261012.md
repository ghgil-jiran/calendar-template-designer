# 표지 연도와 CALENDAR 개체 분리

- 표지의 숫자 + CALENDAR 구성은 연도 자동 연결 텍스트와 고정 보조 문구 텍스트로 분리한다.
- 한 줄은 가로, 두 줄은 세로 기본 배치로 생성한다. 각 개체의 글꼴, 크기, 색, 위치, 회전을 별도로 편집한다.
- 기존 표지의 합쳐진 연도 개체도 편집 및 저장 원본 정규화 시 같은 구조로 전환한다. 원래 연도 개체 ID는 유지한다.
- 전환 이후 페이지 설정은 개체의 저장된 문구/스타일을 덮어쓰거나 삭제한 보조 문구를 다시 만들지 않는다. 명시적인 페이지 구성 재적용은 기존 기능에 따라 배치를 다시 적용한다.
- 연도 연결을 해제하면 고정 문구를 저장한다. 사용자 서비스도 같은 공통 개체 모델을 사용한다.
- 제작 교정 문서는 자동 전환하지 않는다. 기존 접수본/교정본의 원본 형태를 유지한다.

검증: 한 줄/두 줄 전환, 연도 변경, 180px 연도/17px 보조 문구 독립 스타일, 저장·재불러오기, 삭제 보존, 고정 문구, 숫자만 및 비표지 페이지 보존. 사용자 서비스에서는 자동 연도 치환과 고정 보조 문구/스타일 보존을 검증한다.
