# 템플릿 이미지 인쇄 품질 검사

4단계는 템플릿 실제 페이지에서 사용하는 이미지와 사진 프레임 전체를 검사한다. AI 생성 여부 설정으로 공통 검사를 생략하지 않는다. 등록만 하고 사용하지 않는 라이브러리 자산은 제외한다.

공통 항목은 페이지·개체 연결, 원본 접근과 디코딩, 실제 배치·맞춤·확대 배율 기준 300 DPI, 확대 선명도·잘림·최종 CMYK PDF의 색상과 계조, 흐림·노이즈·깨짐이다. 뒤의 두 항목은 관리자 육안검사로 기록한다. 같은 이미지도 사용 위치별 해상도를 계산한다.

실제 AI 사용 위치가 있으면 생성 기준·최대 품질 근거와 비정상 형상·원치 않는 문자·숫자를 추가한다. 생성 기준 근거가 부족하면 자동 통과하지 않고 관리자 확인을 요구한다.

사용자 교체용 빈 프레임은 검토 대상으로 남으며, 이미지 입력 또는 삭제 전에는 완료되지 않는다. 이미지가 전혀 없으면 4단계는 대상 없음으로 판정한다. 1~3단계의 완료 조건과 최종 PDF 검사 기준은 유지한다.

검사 결과는 기존 인쇄 Job 보고서의 `checks.templateImagePrintQuality`에 저장한다. 공통 5항목 / AI 포함 7항목이며 `template-image-print-quality.v2@0.1.0` 버전을 사용한다. 사용 위치 목록과 원본·배치·크롭의 서명을 함께 저장한다. 이미지나 배치를 수정하면 이전 육안 승인으로 완료할 수 없다. 재조회 후 원본·해상도 자동검사를 다시 실행한다. 동일 원격 자산의 재조회용 임시 URL 변화는 실제 자산 변경으로 취급하지 않는다.

기존 `aiImagePrintQuality`와 저장 API는 호환을 위해 보존하지만 새 전체 이미지 검사 완료 근거로 승계하지 않는다. 사용자 서비스에서 교체한 최종 이미지의 검사와 실제 인쇄 PDF 검증은 후속 범위다.

검증: 일반 업로드·공통 그래픽·AI 혼합·미사용 AI 자산·저해상도·원본 오류·빈 프레임·재배치·원본 교체·서명 유지·5단계 연결 및 결과 저장 API의 필수 항목·중복·개수 검증.

육안·생성 근거 판정은 자동검사 진행 전에도 저장할 수 있다. 저장 중에는 중복 클릭을 막고, 성공·실패를 화면에 계속 표시한다. 자동검사가 미완료이거나 실패인 상태에서는 육안 통과 기록만으로 4단계·최종 완료를 승인하지 않는다.
