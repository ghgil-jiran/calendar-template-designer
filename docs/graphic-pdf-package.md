# PDF 배경 패키지

공통 그래픽 라이브러리에서 패키지 생성 시 PDF 방식을 선택합니다. 기존 벡터 패키지는 그대로 사용할 수 있습니다.

- 샘플 PDF: 전체 디자인 참고 자료입니다. 배경으로 자동 적용하지 않습니다.
- 배경 PDF: 여러 파일을 등록하고 문서의 각 페이지를 표지·간지·월력 앞뒤·뒷표지 슬롯에 지정합니다. 월력 번호는 시작 월부터의 순서입니다.
- 파일당 최대 250MiB, 160페이지입니다. 원본을 1MiB 단위로 전송하며 재선택 시 확인된 조각을 재사용합니다. 업로드는 최대 4개 조각을 병렬 전송하고 수신 조각의 크기·해시를 확인합니다. 등록 완료 시에는 수신 기록으로 누락을 검사하며 원본 전체를 다시 읽지 않습니다. 원본 검증·미리보기 준비 버튼에서 같은 파일을 선택하면 전체 SHA-256 검증과 PDF 구조 확인·미리보기를 별도로 수행합니다. 등록된 원본은 덮어쓰지 않습니다.
- 화면에서는 최대 1600px WebP 미리보기를 사용합니다. 원본 PDF는 별도 보관하며 다운로드 시 해시를 재확인합니다.
- 현재 템플릿 적용 규격은 260×180mm 또는 도련 포함 266×186mm 배경입니다. 그 밖의 규격은 원본 등록은 가능하지만 적용은 거절합니다.
- 템플릿에는 패키지 버전과 원본 문서·페이지·해시 및 미리보기 자산 참조가 저장됩니다. 기존 텍스트와 월력 개체를 유지합니다.

## 인쇄 범위

이 기능은 원본 보존·등록·화면 배경 연결까지 제공합니다. 최종 인쇄 PDF에 원본 PDF 페이지를 직접 합치는 기능은 별도 구현이 필요합니다. 해당 배경이 있는 프로젝트는 네이티브 인쇄 사전 검사에서 PDF_SOURCE_EMBEDDING_REQUIRED로 차단하여 화면 미리보기를 인쇄 원본으로 오인하지 않게 합니다.

## 검증 범위

서버 조각 업로드·재개·해시·권한 경로와 매핑/기존 UI 회귀 검사는 자동 검사 대상입니다. 실제 대용량 원격 업로드, 인증된 브라우저 조작 및 최종 인쇄 품질은 별도로 확인해야 합니다.

원본 등록 완료와 검증 완료는 구분됩니다. 검증 대기 파일은 배경 연결 및 인쇄 원본 사용이 불가능합니다. 별도 처리는 자동 백그라운드 작업이 아니며, 동일 파일 선택으로 명시적으로 시작합니다. 기존에 전송 중이던 파일도 같은 패키지·파일로 재개할 수 있습니다. 브라우저를 닫으면 현재 요청 결과는 재선택 후 확인해야 합니다.
