# 학사달력 V2 전환 작업 기준

기준일: 2026-11-17. 상태: 현황 조사 착수. 운영 변경 및 전환 완료를 뜻하지 않는다.

## 범위와 운영 원칙

- 당분간 기존 사용자 서비스와 템플릿의 일반 변경은 최소화한다. 필수 수정은 영향과 V2 반영 필요성을 기록한다.
- 기존 시스템을 보존하고 새 시스템에서 탁상형 4개, 벽보형 2~3개만 우선 전환한다.
- 구조 전환으로 기존 결과를 먼저 보존한 뒤 디자인을 수정한다.
- 구버전은 전환 완료 후 운영 경로에서 분리한다. 검증 전에 삭제하지 않는다.

## 순서와 중간 확인

1. 실제 코드·배포·데이터·자산·Worker 관계 조사 및 구버전 기준 확정.
2. 구버전 코드와 데이터 복구 기준 보존. 진행 중 프로젝트·주문·인쇄 처리 범위 확인.
3. V2 작업 브랜치·배포 프로젝트·데이터 저장 범위 분리.
4. 공통 저장 형식·개체 식별·스타일·연결·권한·월별 변화 계약 정의.
5. 공통 런타임과 렌더러 정리.
6. 에디터 개편 및 저장·다시 열기 검증.
7. 사용자 서비스와 Worker를 동일 렌더링 기준에 연결.
8. 샘플 A를 별도 초안으로 전환하여 최종 PDF까지 검증.
9. 나머지 운영 템플릿 전환·검증.
10. Production 운영 전환과 복구 확인.
11. 구버전 실행 코드·배포 의존성 분리.

8단계 이전에도 V2 배포 분리, 개체 현황과 편집 도구, 샘플 A 일부 페이지를 단계별로 확인한다. 화면 확인과 전체 인쇄 검증 완료는 구분한다.

## 합의한 편집 기준

- 콘텐츠: 미선택 시 페이지 개체 목록과 연결 여부, 선택 시 내용과 연결 설정.
- 데이터 탭은 콘텐츠로 통합한다.
- 스타일: 배경 자산을 제외한 구성 개체·배치·서브 스타일 조합. 선택 개체에서 묶음과 세부 속성을 편집한다.
- 수정값은 템플릿에 유지하고, 별도로 템플릿 전용 또는 공통 스타일로 등록한다. 공통 원본의 변경은 기존 적용본을 자동 변경하지 않는다.
- 배치는 캔버스 중심, 좌표·크기는 접힌 세부 설정, 명령은 툴바로 정리한다.
- 자동 저장 상태를 표시하고 미저장 변경이 남았을 때 이탈을 확인한다. 초안 저장과 편집 이력 생성 정책은 별도 정의한다.
- 권한은 페이지의 개체 추가 허용과 개체별 편집 허용을 구분한다. 개체 목록을 펼쳐 설정하고 선택 항목을 자동으로 연다.
- 연결 내용 변경은 같은 연결 대상에 반영하고 스타일·배치는 유지한다.
- 구성·스타일·배치 전체 적용은 대상 역할과 앞면·뒷면 범위를 명시한다.
- 공통 구성과 월별 내용·변화값을 분리한다. 페이지 바탕색·월 제목색·요일색 등은 고정값 또는 월별 값 연결로 지정한다.
- 월 표시와 월 격자는 독립된 스타일 묶음과 세부 설정을 제공한다.

## 보존 및 V2 분리 전에 남은 확인

- 실제 GitHub 최신 커밋과 양 서비스 Production 배포 커밋 대조.
- 현재 관리자 저장 초안과 검증된 원본, 배경 PDF·폰트 등 참조 자산의 목록·복원 범위.
- Worker 원본 저장소·사용자 PC 실행본·로컬 서버의 작업 조회 및 결과 저장 경로.
- DB·Storage 공유 범위와 V2 쓰기 격리 방법. 비밀 값은 문서에 기록하지 않는다.
- 기존 사용자 프로젝트·주문·진행 중 작업의 전환 또는 구버전 마무리 범위.
- 전체 검사 기존 실패와 새 변경으로 발생한 실패 구분.
