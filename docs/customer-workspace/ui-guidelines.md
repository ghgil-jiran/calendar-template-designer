# 사용자 서비스 화면과 제한 편집 기준

## 글자와 색

일반 서비스 화면은 페이지 제목 30px(모바일 26px), 영역 제목 20px, 소제목 16px, 입력 항목명/선택 항목/버튼 14px, 안내문 13px, 진행 상태/배지/파일 정보 12px를 사용한다. 제목·입력 내용은 foreground, 보조 안내는 help-foreground, 선택 상태는 primary, 오류는 destructive로 구분한다. 안내 상자는 soft 배경과 왼쪽 강조선으로 제목·입력 항목과 구분한다.

사용자 편집기는 도구 밀도를 고려해 상단 프로젝트명·사이드 제목 16px, 속성 제목·항목명 14px, 안내문 13px, 상태·파일명 12px를 사용한다. Hero 문구는 기존의 강조용 크기를 유지한다. 실제 달력 안의 글꼴·크기·색상은 변경하지 않는다. 화면 기준은 globals.css의 type 변수로 관리한다.

## 현재 사용자 편집 범위

공통 권한과 사용자 편집기가 지원하는 기능의 교집합을 제공한다. 현재는 사진 교체와 사진 틀 내부 맞춤만 제공하며, 개체 이동·크기 변경·글자 변경은 신규 작업에서 차단한다. 선택한 개체에 편집 기능이 없으면 명시적으로 안내한다. 선택하지 않은 상태에서는 제한 편집 원칙과 선택 방법을 안내한다.

기존 저장 프로젝트의 유효한 배치·글자 조정은 읽기 호환성을 위해 보존한다. 사진 편집 되돌리기도 과거의 배치 조정을 바꾸지 않는다. 템플릿 에디터의 별도 제한 권한 프리셋 추가는 이번 작업에 포함하지 않는다.

## 저장과 사진 선택

편집기의 사진 맞춤은 즉시 반영한다. 변경 후 약 0.8초 동안 추가 변경이 없으면 기존 내 프로젝트 저장 방식(같은 브라우저의 IndexedDB)으로 자동 저장한다. 저장 중 새 변경이 발생하면 이후 최신 상태를 다시 저장한다. 실패 시 편집 내용과 이전 저장본을 유지하며, 실패 상태를 표시하고 저장 버튼으로 재시도할 수 있다. 편집기를 나갈 때에도 저장한 뒤 달력 확인으로 이동한다. 입력 단계 전체의 자동 저장으로 범위를 확장하지 않는다.

페이지별 사진 배정은 썸네일 선택 창으로 사진을 고른다. 현재 선택과 사용 중 상태를 표시하며, 같은 사진을 여러 영역에 사용할 수 있다. 선택은 기존처럼 적용 대기 상태가 되고 '이 페이지에 적용하기'로 반영한다. 사진 사용 페이지 탐색·대량 사진 검색/분류·페이지 진행 상태·완료 후 추가 안내는 보류한다. 사진 전체 50장 제한을 유지한다.
