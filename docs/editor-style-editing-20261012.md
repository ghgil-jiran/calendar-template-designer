# 개체 콘텐츠·스타일 편집 정합성 수정 — 2026-10-12

템플릿 에디터의 저장값과 편집 화면/사용자 서비스 화면이 다른 문제를 수정했다.

- 월간 일정과 일반 일정 목록도 공통 일정 렌더러에서 글꼴, 크기, 굵기, 색, 행간, 제목 위치/배경, 내용 배경, 전체 영역 배경/테두리를 읽는다. 연간 월별 일정의 월 영역 설정은 해당 표시 방식에만 노출한다.
- 월 제목은 자동 월 제목과 직접 입력을 구분한다. 기존 titleTemplate 및 자동 월 제목은 유지한다. 연간 월별 방식에서 사용하지 않는 목록 제목/표시 개월/일반 단 구성/자동 축소 설정은 숨긴다.
- 일반 일정의 자동 단 구성/축소 계산을 공통 모듈로 옮겨 사용자 서비스에서도 같은 계산을 사용한다. 출력에서는 영역 초과 안내를 숨긴다.
- Yearly Plan 월 텍스트를 고정 문구로 전환할 수 있다. 자동 월 표시를 선택하면 월 형식(영문/한글)과 학년 전환을 유지한다.
- 분리된 학교 상징 이미지에는 외부 제목/설명에 적용되지 않는 내부 텍스트 편집을 노출하지 않는다. 분리된 메모 줄 개체에는 제목/개체 유형 편집을 숨긴다.
- 연력은 선택하지 않았을 때 페이지에 연력 개체가 하나인 경우에만 대상을 명시해 스타일을 표시한다. 그룹형 연력에는 무효한 열 수 설정을 숨긴다. 숫자 입력 허용 범위를 실제 렌더링 범위와 일치시킨다.
- 새 스타일 저장 영역도 공통 변경 감지/숫자 검증/저장 상태를 사용한다. 같은 개체에서 한 영역을 저장해도 다른 영역의 미저장 입력을 보존한다.
- 저장 및 변경 여부 계산은 복사본을 정규화하므로 원본 프로젝트를 변경하지 않는다. 다시 불러올 때 동일한 개체 구조를 유지한다.
- 최종 편집 화면에서 일반 텍스트/이미지/위젯의 회전을 적용한다. 도형/프레임 선 두께 0을 기본 두께로 덮어쓰지 않는다. 사용자 서비스의 텍스트 불투명도는 텍스트 스타일 값을 우선한다.

검증: 에디터 전체 Studio 회귀 836개 및 패키지/빌드 검사 통과. 사용자 서비스 전체 테스트 931개 통과, 2개 기존 제외, Next 빌드 통과. 저장·재불러오기, 5가지 일정 표시 방식, 고정 월 텍스트, 다중 영역 입력 보존, 최종 회전, 자동 축소를 실행 테스트로 재현했다.

실제 로그인 후 브라우저 클릭/재접속 검증은 별도 진행한다. Preview만 배포하며 Production Promote는 포함하지 않는다.
