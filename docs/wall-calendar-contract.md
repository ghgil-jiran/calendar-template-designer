# 벽보형 월력 계약

- 내부 유형 ID poster 및 year-calendar는 유지하고 표시 명칭을 벽보형·전체 월력으로 통일한다.
- 달력 유형의 wallCalendarDefaults는 기존 binding_policy JSON에 저장한다. 새 템플릿의 기본값이며 기존 템플릿은 전체 월력에서 별도로 적용한다.
- 전체 월력 기본 설정 → 개별 월 설정 순으로 적용한다. 다른 페이지에 스타일을 적용해도 월 연결·연도·일정·위치·크기는 유지한다.
- 글자는 인쇄 pt, 간격과 선은 mm 기준으로 계산한다. 매월 6주를 확보한다.
- 기본 스타일은 날짜 월력 + 월별 일정 목록형이다. 날짜 칸에는 숫자만 표시하고, 공휴일 날짜색은 유지한다. 학교 일정과 공휴일·기념일은 소제목으로 구분해 하단 목록에 표시하며, 각 영역 안에서 날짜순으로 정렬한다. 날짜순 통합 목록도 선택할 수 있다. 24절기·음력은 기본 제외하며, 켰을 때는 기본 달력과 같은 저장된 참조 자료를 그대로 사용한다.
- 사용자 서비스는 적용 스타일(간결형/격자형/일정형), 월 제목 형식·배경, 요일 형식·표시, 날짜 정렬, 격자, 일정 위치, 공공 정보 위치, 목록 구분과 단 수를 허용한다. 서체 크기·월 배치·월 연결은 관리자 설정을 유지한다.
- 공간 부족은 편집기에 경고하고 확인용 PDF 및 에디터 인쇄 경로에서 차단한다. 내용을 자동 생략하지 않는다.
- 코드 검사와 배포 READY는 실제 관리자 조작·실물 인쇄·Acrobat PDF/X 검사 통과를 뜻하지 않는다. 등록 템플릿 재저장과 1페이지/2페이지 실물 검증은 별도 수행한다.

- 포함 정보의 기준은 project.settings.calendarData이며 기본 설정과 전체 월력의 포함 정보 메뉴가 같은 값을 수정한다. 유형 기본값은 새 템플릿에 복사하고, 월별 스타일을 바꿔도 데이터 포함 여부는 모든 월에 공통 적용한다.
- 전체 월력 편집과 유형 기본값은 접기/펼치기로 분류한다. 적용 스타일·배치, 날짜·요일·격자, 월별 목록, 포함 정보, 날짜 칸 세부 표현, 글꼴·색상, 공통 적용·공간 검사를 구분한다.

## 2026-11-14 표시 스타일과 목록 개선

- 적용 스타일은 표시 속성만 변경한다. 공휴일·기념일·음력·24절기 포함 여부, pt 크기, 월 연결, 월별 개별 설정의 범위, 개체 배치와 데이터는 유지한다.
- 날짜만 표시할 때 요일과 날짜는 같은 7열의 가운데 정렬을 사용한다. 날짜 칸 정보형에서는 왼쪽 정렬을 기본으로 한다. 수동 정렬도 선택할 수 있다.
- 월 제목은 한글/숫자+영문/숫자, 배경은 색상 띠/없음/밑줄, 요일은 한글 약식/전체/영문을 제공한다.
- 목록은 날짜와 내용을 분리하고 긴 제목은 내용 시작점에 맞춰 줄바꿈한다. 해당 월 안의 날짜는 일 숫자로 줄이며, 월을 넘는 기간은 다른 월의 월/일을 함께 표시한다.
- 다단 목록은 CSS 다단 흐름으로 한 단의 위에서 아래로 읽고 다음 단으로 이동한다. 각 항목은 단 사이에서 분리하지 않는다. 학교 일정과 공공 정보는 서로 독립된 소제목 아래 흐른다.
- 목록 단 수는 자동/1단/2단/3단이다. 자동은 실제 글꼴과 단 폭으로 2단의 내용 높이를 측정하고, 넘치면 3단 결과와 비교한다. 글자를 줄이거나 일정을 삭제하지 않으며 두 구성 모두 넘치면 인쇄를 차단한다.
- 자동 단 수는 공통 Runtime에서 수행하고, 폰트 로드 후 및 PDF 인쇄 공간 검사 직전에 다시 계산한다. 편집기와 사용자 서비스가 별도 목록 렌더러를 사용하지 않는다.
- 전체 월력 설정과 월별 설정에서 같은 항목을 제공한다. 스타일 적용은 선택한 범위를 따르며 다른 페이지 적용 시 월 연결은 변경하지 않는다.
