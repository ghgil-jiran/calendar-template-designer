# Calendar Platform V2 foundation

현재는 실행 서비스가 아닌 V2 분리 기반이다. 기존 에디터·사용자 서비스·Worker에서 import하지 않으며 데이터 자동 변환도 하지 않는다.

- `release.json`: 프로그램의 기존 2.0 표기와 구분하는 플랫폼 식별자. `operational: false`는 미가동 상태를 뜻한다.
- `version-boundary.mjs`: 실행본과 작업의 버전 불일치를 거부하는 경계. 실제 PDF 처리나 자산 해시 계산·검증을 대신하지 않는다.
- 인쇄 작업은 저장된 템플릿 버전과 문서·자산 목록 해시를 고정한다. 실제 작업 API 연결은 이후 단계이다.
- 기존 2026-08-05 V2 명세는 참고 자료이며 현재 구현 완료를 의미하지 않는다. 이번 전환 문서와 대조하여 필요한 계약만 단계적으로 확정한다.
- 렌더러는 런타임 릴리스에 함께 묶는다. 한쪽만 바뀌면 호환 검사에서 거부한다.

검사: `node --test platform-v2/version-boundary.test.mjs`

Vercel 프로젝트와 DB 격리 설정은 별도 작업이다. 현행 배포가 이 브랜치를 Preview로 자동 빌드하더라도 그것을 V2 운영 환경으로 취급하지 않는다.
