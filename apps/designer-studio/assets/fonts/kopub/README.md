# KoPub Batang

Font family: `KoPub Batang` (KoPub 바탕체, not KoPub World).

Sources:
- https://github.com/google/fonts/tree/main/ofl/kopubbatang
- https://fonts.googleapis.com/earlyaccess/kopubbatang.css
- Original Google Fonts TTF files at `https://raw.githubusercontent.com/google/fonts/main/ofl/kopubbatang/KoPubBatang-{Light,Regular,Bold}.ttf`

Weights: 300 Light, 400 Regular, 700 Bold. The distribution includes SIL OFL 1.1 in OFL.txt. Original TTF files are loaded without modification, using the same shared stylesheet in the editor, customer renderer and DOM printing. Network access to raw.githubusercontent.com is required, as with the existing externally hosted Google fonts.

User reported submitting a use-registration request on 2026-11-17. This is not recorded as an approval received.

Removal if requested: remove the three KoPub faces from shared-screen-fonts.css and the KoPub Batang entries in object-editing.js, page-widget-styles.js, template-settings-library.js and shared-screen-month-title.js; rebuild the customer shared renderer.
