# Calendar Template Designer v1.0 Beta RC4

`index.html`을 최신 브라우저에서 엽니다.

RC4는 기존 편집 화면을 유지하면서 모든 렌더링 이후 Template Runtime을 Shadow mode로 실행합니다.

브라우저 콘솔 API:
- `ACDLRuntimeBridge.execute()`
- `ACDLRuntimeBridge.lastDocument`
- `ACDLRuntimeBridge.getCurrentPage()`

좌하단 Runtime 배지를 클릭하면 페이지 수와 진단 건수를 확인할 수 있습니다.
