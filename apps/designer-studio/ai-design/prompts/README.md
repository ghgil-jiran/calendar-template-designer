# AI 디자인 생성 프롬프트

실제 생성 로직이 읽는 단일 원본은 `school-calendar-design@0.13.0.js`입니다. AI는 편집 개체의 모양을 흉내 내지 않고 여백과 부분 색면을 활용한 현대적인 조형 시스템을 생성합니다. 공통 금지 규칙, 6개 페이지 역할별 프롬프트, 실제 페이지 구성, 월력 앞면과 뒷면의 분리된 변화 방식을 함께 관리합니다. 0.13.0부터 재료 중심 스타일을 에디토리얼 그래픽·캠퍼스 다큐멘터리·모듈러 컬러·컨템퍼러리 일러스트레이션·디지털 오라 모션·한국적 모던 그래픽으로 교체하고, 대각선 반복을 금지하며 월력 격자 아래의 연속적 배경을 명시합니다.

## 버전 원칙

- patch: 표현 개선과 오탈자 수정
- minor: 페이지 역할, 보호 영역 또는 생성 계약 추가
- major: 출력 구조나 호환성을 바꾸는 정식 계약 변경

기존 버전은 생성 결과 재현을 위해 삭제하지 않습니다. 생성 자산에는 사용한 `PROMPT_SET_ID`, 페이지 역할, 방향과 월 정보가 기록되어야 합니다.

## 편집 책임 경계

AI는 배경·패턴·장식·일러스트·빈 프레임 자산과 초기 배치를 제안합니다. 연도, 월, 날짜, 일정, 학교 정보, 교표, 사진, 달력, 플래너와 메모는 별도 편집 개체로 유지합니다. 최종 개체 수·위치·크기·중복 여부는 편집자가 조정합니다.
