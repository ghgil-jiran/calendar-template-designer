# 사용자 편집기 공통화 — 첫 개발 범위

기준: feat/customer-editor-shared-engine. 안정 브랜치 preview/customer-workspace-20261107에서 분리. Production/기존 사용자 서비스는 변경하지 않는다.

## 현재 구현

- 입력 확인에서 전체 화면 편집 공간으로 진입한다. 사이트 헤더/입력 저장 패널/푸터를 제외하고 상단 작업 도구, 왼쪽 사진 썸네일, 중앙 원본 렌더러, 오른쪽 속성, 하단 페이지 썸네일로 구성한다. 사진 끌어 넣기와 영역 선택 후 썸네일 클릭을 모두 제공한다.
- 기존 inspector-graphic의 사진 맞춤 처리를 photo-frame-editing.js로 추출했다. 디자이너 Inspector와 새 사용자 세션 모두 그 모듈을 호출한다. 기존 디자이너 전체 세션을 새 세션으로 이전한 것은 아니다.
- editor-session.js는 DOM/관리자 저장과 분리된 문서 세션이다. 개체 권한·공통 visibleElements를 사용한다. 사진 프레임의 교체/fit/scale/offsetX/offsetY, 일반 이미지 교체, 허용된 개체의 위치/박스 크기/글자 크기를 지원한다. 표지·학교 상징·뒷표지에서만 이동/박스/글자 크기를 허용하며 원본 권한도 함께 확인한다. 월별 사진 페이지의 프레임 배치는 보호한다. 이동은 공유 canvas-geometry, 배치·글자 크기 반영은 공유 inspector-element를 사용한다. 사진 선택만으로 이력을 만들지 않는다. 적용 단위 실행 취소/다시 실행을 제공한다.
- Master 사진 편집은 shadowOfMasterElementId를 가진 현재 페이지 전용 개체로 보관한다. 개별 교체가 허용된 경우에만 입력 연결을 해제하고 해당 영역의 사진을 바꾼다. 다른 페이지의 Master와 사진은 유지한다.
- 프로젝트 editorState(version=1)는 페이지 ID와 검증 가능한 사진 편집 목록을 저장한다. 이미지 URL 대신 사진 원본 ID를 참조한다. 기존 입력 반영 결과에 편집 목록을 적용한 완성 문서도 appliedProject에 보관한다.
- 저장/백업/복원 때 편집 목록을 다시 적용해 권한·대상·사진 원본을 검증하고 appliedProject와 비교한다. DB/프로젝트 스키마를 바꾸지 않고 optional 필드로 확장한다. 기존 프로젝트를 수정 없이 읽는다.
- 입력 정보 변경은 기존 편집을 유지하면서 새 입력 문서에 적용된다. 사진 입력에서 특정 영역의 배정을 바꾸면 그 영역의 기존 편집을 제거한다. 사진 삭제는 편집에서 사용 중인 경우도 확인하고 관련 참조를 제거한다.
- 공유 배치 모듈의 module.exports는 ESM 환경에서 Next 페이지 번들을 덮어쓰므로 제거했다. 기존 global API와 계산은 유지한다.

## 범위 밖

- 임의의 개체 추가/삭제/회전/꾸미기, 문구 내용 편집, 일정 파일 해석, 주문 및 인쇄 승인. 제한된 페이지의 허용된 배치와 글자 크기만 조정한다.
- 자동 서버 저장/로그인/기존 시스템 진입 연계. 저장은 같은 주소·PC·브라우저의 기존 내 프로젝트와 백업을 사용한다.
- 실행 취소 이력은 세션 내 최대 20회이며 재열기 후 이력은 초기화한다. 편집 결과는 유지한다.

## 다음 순서

1. 공통 세션의 사진 선택/권한 경로를 디자이너 쪽에서도 점진적으로 사용하도록 연결.
2. 현재 제한된 이동/크기/글자 크기 기능을 실제 템플릿으로 검증하고 직접 조작과 넘침 안내를 개선.
3. 연결된 학교 문구와 자유 문구를 구분해 편집 연결.
4. 사진 보관함과 전체 페이지 작업 UX를 실제 대량 사진으로 개선.
5. 편집 문서와 최종 미리보기/출력 일치 검증.

별도 Preview는 다른 origin이다. 기존 Preview에서 저장한 내 프로젝트는 자동으로 나타나지 않는다. 기존 주소에서 백업을 내려받아 새 주소에서 불러오면 된다. Private 사용자 자료/실제 템플릿 소스는 저장소에 올리지 않는다.

## 검증 (전체 화면 첫 버전)

앱46개, 기존 Inspector/좌표 및 사용자 권한 검사 통과. 로컬 Chromium에서 전체 화면 분리, 사진 썸네일 드래그/클릭 배정, 월별 프레임 배치 보호, 표지 텍스트 박스/글자 크기/포인터 이동, 실행 취소/다시 실행, 다른 월 불변, 저장/재열기, 360px 표시를 확인했다. 하단 썸네일은 화면에 나타나는 면부터 표시하고 해당 페이지 편집이 바뀔 때 갱신한다. 실제 원격 브라우저 검증과 로컬 fixture 검증을 구분한다.

## 2026-11-08 · 편집기 메뉴·도구 바·사진 추가·선택 표시 정리

- 상단은 저장/미리보기 메뉴/전체 확인으로 정리하고 실행 취소·재실행/페이지 이동/확대는 독립 도구 바로 이동했다. 미리보기는 현재/전체 시작 위치를 선택해 모달로 열며 편집 상태를 바꾸지 않고 페이지를 넘겨 볼 수 있다.
- 왼쪽은 보관함 제목/장수/안내/사진 추가/범주 탭/사진 목록으로 영역을 나눴다. 편집기에서 JPG/PNG/WebP 원본을 추가하고 즉시 끌어 넣거나 선택할 수 있다. 기존 사진 입력과 addPhotoFiles 공통 처리로 25MB/50장/합계250MB/중복 처리를 공유한다. 세션의 setAssets는 기존 실행 취소 이력을 유지한다.
- 오른쪽은 선택 개체 요약과 이미지/텍스트별 허용된 조정 그룹을 제공한다. 선택선은 원본 에디터 표현을 참고한 1px 테두리/작은 개체 태그/권한이 있을 때만 실제 모서리 resize 핸들로 변경했다. 좌표와 크기 계산은 공통 canvas-geometry를 사용한다.
- 앱48개, 관련 Inspector/좌표/권한14개와 타입/스타일/빌드 통과. Chromium에서 1600×900/1024×650 화면 맞춤, 확대 시 내부 스크롤, 툴바 분리, 추가 사진 즉시 사용/재열기, 모서리 크기 조절, 미리보기 모달/페이지 이동, 기존 드래그/클릭/저장/모바일 흐름 통과. 원격 브라우저 확인과 로컬 fixture 검증은 구분한다.
