# 학사일정 가져오기

사용자 서비스의 `POST /api/workspace/schedule`이 사용하는 서버 전용 엔진입니다. 엔진 버전은 이 디렉터리의 `package.json`에서 관리하고 API의 `engineVersion`에 반환합니다.

- 월별 일정표 HWPX와 날짜가 명시된 한 열의 텍스트 PDF는 날짜와 일정명을 원본에서 읽습니다.
- 그 외 지원 파일은 사용자 서비스 서버에서 AI 분석을 실행합니다. 스캔 PDF와 표 구조가 모호한 PDF도 이 경로를 사용합니다. 사용자 서비스에 `ANTHROPIC_API_KEY`를 서버 환경변수로 설정해야 합니다.
- AI 분석에는 공식 공휴일 제외와 기간 보정이 적용됩니다. 응답에 원본 대조 안내를 포함합니다. 추가 분석은 앞선 결과에 일정을 보충합니다.
- 파일 한도는 3MB입니다. DOC와 HWP는 각각 DOCX와 HWPX로 변환할 수 있습니다.

템플릿 에디터에서 연결할 때는 이 API 응답의 `events`, `warnings`, `engineVersion`을 사용합니다. 템플릿 편집 화면용 데이터 변환은 호출부에서 합니다.
