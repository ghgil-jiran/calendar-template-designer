# 연결 확인 목록

이 파일은 구현 완료 범위와 실제 연결 전 확인할 계약을 구분한다. 운영 DB·인증·비밀값·기존 주문 API를 변경하지 않았다.

1. **신원 전달:** 기존 시스템 로그인 후 사용자 ID/이름 전달·검증 방식, 세션 만료/재진입, 사용자별 프로젝트 소유권.
2. **템플릿 조회:** 게시 상태·버전 고정·학교 정보 필요/필수/필수 교체 설정·자산 접근·엔진 요구 버전. 현재 review API는 실제 고객 카탈로그가 아니다.
3. **저장:** 서버 프로젝트 CRUD와 충돌 처리·사진 자산 저장, 새로고침 복원, 저장 기간. 현재는 메모리 입력 검토만 가능하며 서버 저장인 것처럼 표시하지 않음.
4. **제외 규칙:** 필수 교체와 사용자 표시 제외의 우선순위, 제외된 연결 개체의 공통 엔진 처리. 현재 review 필수 텍스트는 제외할 수 없음.
5. **일정:** doc/docx/xls/xlsx/txt의 초기 지원 범위와 해석 계약, 모호한 날짜·학년도 확인. 아직 파일을 읽거나 전송하지 않음.
6. **사진:** 최소 DPI·허용 형식/용량·필수 교체, 프레임 안 crop 저장. 기존 원본을 유지하는 자산 참조 필요.
7. **주문/출력:** 최종본 식별자와 전달 규격, 비동기 인쇄본 생성·검증과 기존 시스템 연결. 공식 member/print 문서와 새 흐름을 대조해야 함.
8. **엔진:** 실제 renderPage 전역/DOM 의존성 분리 후 단일 엔진 연결. 현재 참고 이미지 미리보기는 그 검증을 대신하지 않음.

다음 단계의 실제 저장에는 인증·권한 계약이 필요하다. 개발 화면을 넘어서 임의 사용자 ID로 서버에 데이터를 쓰는 API를 추가하지 않는다.

## 자료 입력 구현 · 2026-11-07

- 학교 정보 → 학사일정 → 사진 → 자료 확인을 연결했다. 현재 입력과 사진 File 객체는 화면 메모리에만 유지한다. 업로드·서버 저장 완료로 표시하지 않는다.
- 일정: DOCX/XLSX/UTF-8 CSV/TXT, 3MB 이하. 시작·종료일·일정명 수정/추가/삭제 및 읽지 못한 내용 확인. DOC/XLS·암호화·손상 파일은 명시적으로 거절한다.
- 사진: JPG/PNG/WebP, 한 장 25MB·50장·합계 250MB. 원본 보존·선택 취소·픽셀 크기 및 배치 DPI 안내. 저장소 업로드·보존은 아직 없다.
- 실제 문서를 받으면 템플릿 입력 요구사항과 동일한 편집 권한 정의에서 항목/사진 영역을 도출한다. 프레임 배치를 바꾸지 않고 학교 자료와 사진 소스만 변경한다.
- 페이지 표시는 빌드 때 에디터의 기존 렌더링 함수/호환 처리와 공용 화면 모듈을 읽어 생성한다. 생성 파일은 직접 편집하거나 커밋하지 않는다. 관리자 초기화·저장 API는 고객 앱에 실행하지 않는다.
- 게시 목록 연결은 서버 설정을 별도로 완료한 뒤 활성화한다. `CUSTOMER_CATALOG_MODE=published`에서는 게시 상태 및 고정 버전을 확인하며 조회 실패를 참고 데이터로 숨기지 않는다. 자산 URL은 해당 게시 문서가 참조하는 자산만 발급한다.
- 현재 새 배포의 환경변수 목록은 비어 있다. 실제 게시 목록·운영 DB 조회는 검증하지 못했다. 기존 서비스 템플릿 API도 인증 없이 401을 반환했다. 운영 환경변수·인증·DB 정책은 변경하지 않았다.
- 실제 프로젝트 저장·사진 자산 저장·새로고침 복원에는 기존 시스템의 신원 전달/검증과 사용자별 소유권 계약이 먼저 필요하다. 관리자 세션을 고객 신원으로 사용하지 않는다.
- 로컬 검증: 일정 형식/유효 날짜/기간/중복, 입력 제외, 원본 불변, 권한, 월별 사진 분리 검사. 샘플 A 스냅샷을 로컬에서 직접 제공한 28면 및 입력 반영 검사는 운영 DB 연동 검증과 구분한다.
