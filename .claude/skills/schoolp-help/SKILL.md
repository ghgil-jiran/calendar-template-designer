`AI_COMMANDS.md`의 공식 요청 표(자주 쓰는 6개)와 짧은 사용 안내를 보여준다.

- 슬래시는 보조라고 함께 안내한다.
- 6개: 실행 / 작업 저장 / 불러오기 / 배포 / 핸드오프 / 도움말.
- 새 화면·기능은 만들 내용을 그대로 설명하면 AI가 필요한 내용을 확인한 뒤 진행한다고 안내한다.
- 막히거나 궁금한 점은 상황을 그대로 질문하면 된다고 안내한다.
- 점검과 최신 기준 확인은 필요한 시점에 AI가 처리하고, Supabase 데이터 확인은 요청하면 된다고 안내한다.
- FAQ나 긴 스타터 설명은 붙이지 않는다.
