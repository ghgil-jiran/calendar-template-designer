`AI_COMMANDS.md`의 "배포해줘" 절차와 "Vercel 준비 자동화"를 그대로 따른다.
- 배포 전 `npm run build`. 저장 안 된 변경이 있으면 먼저 저장할지 짧게 확인한다("저장하고 배포해줘"면 질문 없이 저장 후 배포, "배포만 해줘"면 저장 없이 배포).
- 공식 도메인·운영 환경변수·DB 전환·사용자 공개 반영은 개발자 확인 후 진행한다.
