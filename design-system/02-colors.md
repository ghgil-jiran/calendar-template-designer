# Academic Calendar Design System — Colors

## Core palette

### Primary Blue — `#2563EB`
신뢰와 집중을 표현하는 대표 색상.

사용:
- 주요 버튼
- 선택 상태
- 활성 탭
- 포커스 링

사용하지 않음:
- 오류
- 경고
- 넓은 배경 전체

### Primary Hover — `#1D4ED8`
주요 버튼과 선택 요소의 hover 상태.

### Primary Soft — `#EFF6FF`
선택 카드, 안내 영역, 약한 강조 배경.

### Accent Teal — `#0F9F8F`
완료, 적용, 정상 상태처럼 긍정적인 피드백에 제한적으로 사용.

### Warning — `#D97706`
주의가 필요하지만 작업을 막지 않는 상태.

### Error — `#DC2626`
삭제, 실패, 유효성 오류처럼 명확한 위험 상태.

## Neutral palette
- Canvas: `#F6F8FB`
- Surface: `#FFFFFF`
- Surface Subtle: `#F8FAFC`
- Border: `#E2E8F0`
- Border Strong: `#CBD5E1`
- Text Strong: `#0F172A`
- Text: `#334155`
- Text Muted: `#64748B`
- Text Disabled: `#94A3B8`

## Usage rule
한 화면에서 강조색은 Primary Blue를 중심으로 사용하고 Accent Teal은 상태 표현에만 사용한다. 새로운 임의 색상은 추가하지 않는다.
