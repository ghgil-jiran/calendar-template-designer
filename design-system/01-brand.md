# Academic Calendar Design System — Brand

## Brand statement
학교 출판물을 쉽고 정확하게 완성하는 전문 디자인 도구.

## Product personality
전문적이지만 어렵지 않고, 차분하지만 무겁지 않으며, 창의적이지만 산만하지 않다.

## Design principles

### 1. Content First
UI는 콘텐츠를 돋보이게 하고 편집을 지원한다. 장식이 결과물보다 먼저 보이지 않게 한다.

### 2. Calm UI
색, 그림자, 움직임을 절제한다. 장시간 작업에서도 시각적 피로를 줄인다.

### 3. One Click Less
반복 작업과 불필요한 확인 단계를 줄인다. 자주 쓰는 행동은 가까운 위치에 둔다.

### 4. Print Friendly
화면의 모든 결정은 최종 인쇄 결과와 연결된다. 크기, 여백, 안전 영역을 명확하게 표현한다.

### 5. Familiar
교사가 별도 교육 없이 이해할 수 있는 용어와 구조를 사용한다.

### 6. Predictable
같은 기능은 같은 위치, 같은 형태, 같은 피드백을 사용한다.

### 7. Progressive
기본 화면은 단순하게 유지하고 고급 기능은 필요한 순간에 단계적으로 노출한다.

## Voice and labels
- 짧고 명확한 한국어 사용
- 내부 기술 용어보다 사용자의 작업 표현 우선
- 명령형 버튼은 동작이 분명해야 함: 저장, 적용, 미리보기, PDF 만들기
- 모호한 표현 지양: 확인, 처리, 실행
