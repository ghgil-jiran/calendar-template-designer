# Academic Calendar Design System — Typography

## Font family
기본 글꼴은 Pretendard를 우선 사용한다. 로드할 수 없는 환경에서는 `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `sans-serif` 순으로 대체한다.

## Scale
- Display: 32px / 1.25 / 700
- Page title: 24px / 1.35 / 700
- Section title: 18px / 1.4 / 700
- Component title: 16px / 1.45 / 600
- Body: 15px / 1.6 / 400
- Body strong: 15px / 1.6 / 600
- Label: 13px / 1.45 / 600
- Caption: 12px / 1.5 / 400

## Rules
- 본문 최소 크기는 14px로 제한한다.
- 버튼은 13px 이하로 줄이지 않는다.
- 긴 설명은 70자 안팎의 줄 길이를 권장한다.
- 숫자와 단위 사이의 간격을 일관되게 유지한다.
- 한 화면에서 제목 굵기는 최대 두 단계만 사용한다.
